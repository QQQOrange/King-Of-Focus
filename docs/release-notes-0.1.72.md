# v0.1.72 / Android 0.4.7 — 分心事件上手机

> 桌面端 0.1.71 已经有了「记一笔」，这一版把它搬到手机上：
> **手机才是分心发生最多的地方**，按钮必须长在锁机遮罩上。

## 一、遮罩上的「记一笔」（Android）

- 专注锁机遮罩的左上角出现「＋ 记一笔」；位置可改到其它三角（设置 → 分心事件 → 按钮位置）。
- 点开 → 输入 → 「记下」，对话框立刻关闭。不跳页、不追问分类。
- 只在**专注锁机**这一档出现：睡眠遮罩、轻档提示页、结束页都不放输入框
  （那几档要么是"该睡了"，要么只是报信，多一个输入框只会分散注意力）。

## 二、分心事件页（Android）

设置 → 「分心事件」→ 打开：

- 顶部：周 / 月视图切换、`‹ ›` 翻页、回到今天。
- 日历：月视图是 7 列日期格（有记录点一个点，全部处理完变绿）；周视图是 7 张日卡。
- 当天清单：**按自律时段分组**，组内按时间倒序，每条显示写入时刻 + 时段标签
  （如 `10:23 写入 · 时段 09:00–12:00`），左侧方框勾选，右侧删除。
- 「清掉这天的已完成」只删已处理的，未完成的一条都不动。
- 设置项就在页面底部：总开关、按钮四角、重复提醒间隔（分钟）、最多追几天。

## 三、提醒（Android）

| 时机 | 行为 |
|---|---|
| 自律时段结束 | 汇总本段未处理条数（`这一段结束了` 通知） |
| 之后每 N 分钟 | 还有欠账就再提醒一次（`分心事件待处理`） |
| 超过 M 天 | 停止提醒 |

`N` 默认 120 分钟、`M` 默认 7 天，都在页面里可调。判据同样用**时间**
（`focusing` 由 true 变 false + 段的计划结束时刻贴近当前 ±3 分钟），
不用"遮罩还在不在"——后者会被暂停/停止本段改写，桌面端踩过这个坑。

## 四、实现要点

- `core/DistractMath.kt`：纯逻辑（时段归属 / 提醒节奏 / 日历计数 / 分组），
  与桌面 `distract.rs` 同一套口径，11 条单测覆盖（含"三小时连成一段"、
  "中间缺一格断开"、"半小时窗口自成一段"、"间隔没到不催"）。
- `data/Distract.kt`：`kof/distract.json`，先写 `.tmp` 再改名；解析失败留档不清空；
  超过 5000 条只丢最老的**已完成**条目。
- 数据**不进 `.kofbak`**：事件流各记各的才说得通（电脑前记的想法不该在手机上再被提醒一遍）；
  设置项也留在本机——两端的"按钮"分别长在 HUD 和锁机遮罩上，位置选项不是同一套语义。
