# v0.1.71 — 分心事件：三秒记下，事后处理

> 主题：专注最常被打断，不是因为想玩，而是因为**一个必须记住的念头突然冒出来**。
> 这一版给念头做了一个出口：HUD 上一个「＋」，写下就走，事后统一处理。

## 一、记一笔（HUD）

- 专注时 HUD 左上角出现一个「＋」（位置可改到其它三角，见设置）。
- 点开 → 输入 → 回车。**记录框不收起**，可以连着记好几条；`Esc` 关闭。
- 输入法选词时按回车不会误提交。
- 记下时不问分类、不追问任务——问了就会打断，下次就懒得记了。

> 遮罩本身是原生覆盖层（设计上"点不到任何东西"），所以按钮放在它上面那层
> HUD 上：视觉上就是"遮罩上的一个按钮"，而且因为 HUD 可以拖动，
> 位置反而是真正可自定义的（窗口位置 + 按钮所在的角）。

## 二、分心事件（新页面，左侧导航）

- 左边：**当天清单**，按自律时段分组，组内按时间排列；每条显示写入时刻 + 时段
  （如 `10:23 写入 · 时段 09:00–12:00`），左侧方框勾选，右侧删除。
- 右边：**日历**。月视图 = 7 列日期格（有记录点一个点，全部处理完变绿）；
  周视图 = 7 张日卡。点任意一天立刻切到那天的清单。
- 顶部：周 / 月切换、`‹ ›` 翻页、回到今天。
- 「清掉已完成」只删当天已处理的，未完成的一条都不动。

## 三、提醒

| 时机 | 行为 |
|---|---|
| 自律时段结束 | 汇总本段未处理条数并通知 |
| 之后每 N 分钟 | 还有欠账就再提醒（带总数） |
| 超过 M 天 | 停止提醒，避免陈年旧账天天弹 |

`N` 默认 120 分钟、`M` 默认 7 天，都在「分心事件」页可改；`N = 0` 表示只在时段结束时提醒。
间隔用落盘的 `nudgedAt` 计算，重启程序不会打乱节奏。

## 四、自律时段自动开遮罩

「分心事件」页给了个近路开关（写的是遮罩页的 `followSchedule`），
改完立刻重算，不等下一拍轮询。新装默认开启——否则记录按钮所在的那层不会出现。

## 五、细节

- 每条事件都记下所属时段的起止与标签；不在时段里记的标「不在自律时段内」，照样保存。
- 判定 `segment_bounds` 是纯函数：相邻小时连成一段，中间缺一格就断开；
  11:00–11:45 这种半小时窗口自成一段（9 条单测覆盖）。
- 写盘用"临时文件 + 改名"，断电不会留半截 JSON；超量只丢最老的**已完成**条目。
- **不进跨设备备份**：这是事件流，跟统计一样各记各的才说得通；
  配置项（开关 / 间隔 / 按钮位置）照常随 `.kofbak` 走。
