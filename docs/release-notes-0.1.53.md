**安卓端一次集中补齐：多套时段、拖滑多选、睡眠、统计、周报、云同步，界面重做；图标三端统一。**

### 界面
- 彻底重做：底部五个页签（总览 / 时段 / 规则 / 统计 / 设置），统一卡片、圆角、字号与间距
- 总览页：状态卡（专注 / 休息 / 自由 / 睡眠）+ 倒计时 + 积分 + 今日使用 + 今日自律，下面直接是权限状态
- 夜间自动跟随系统深浅色

### 时段
- **多套方案**：新建 / 切换 / 重命名 / 删除，每套各自 7×24 排班
- **拖滑多选**：按住拖动一次框选一片格子，反向拖动即取消；松手才落盘
- 番茄参数改动会重排整份方案

### 睡眠
- 到点整机锁住（回桌面 + 全屏遮罩），支持多段与跨夜（23:00 → 07:00）
- 可用积分解锁一小段（默认 10 分钟），紧急情况长按底部文字可解除
- Android 关不了机，所以不承诺"关机"——只承诺"锁住并如实说明"

### 统计与报告
- 守护服务每 15 秒采样前台应用，按小时装桶，一天一个 JSON；熄屏与桌面不计时
- 统计页：今日总时长、24 小时柱状、应用排行、最近 7 天趋势
- 周报：累计 / 日均 / 最长的一天 / 用得最多的应用，可复制或分享

### 云同步
- WebDAV：上传本机、下载覆盖、测试连接；冲突按 `updatedAt` 谁新听谁的
- 账号密码只留在本机，**不随配置上传**；与桌面端同一个目录互不覆盖（手机写 `kof-android.json`）

### 其他
- **去掉专注遮罩**：命中规则不再盖全屏拦截页，改为「回桌面 + 一条通知」；锁机遮罩保留
- **图标统一**：安卓 launcher（含自适应图标）与插件图标都来自桌面端同一张图
- 权限页把「在其他应用上层显示」做成引导流程：先讲清楚为什么，再跳系统页，回来状态自动刷新
- 修复前台识别断流：用户停在同一个应用里时，UsageEvents 没有新事件，现在沿用上次结果并按熄屏跳过

测试：Android 81（新增 20：睡眠跨夜/解锁、统计聚合、周报、云同步冲突、多方案迁移）。
