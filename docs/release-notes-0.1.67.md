# 0.1.67 / Android 0.4.4

## 修复：WebDAV 地址「看着有、其实没有」

地址以前只写在输入框的**灰色示例文字**（placeholder）里，配置里是空串。
于是用户什么都不填，一同步就报「还没有填写 WebDAV 地址」——
那句 placeholder 骗了他。顺带发现自动同步的条件里有 `url 非空`，所以自动同步一次都没跑过。

现在：

- 两端默认地址统一为 **https://dav.jianguoyun.com/dav/KingOfFocus/**，逐字相同
  （`node tools/check_dav_url.js` 会自动比对，不一致直接报错）；
- 配置里留空 = 用默认；手填的自定义地址原样保存、绝不被覆盖；
- 手机端改为**读盘即归一化**，界面上直接显示实际生效的地址，不再靠灰字暗示；
- 目录会在上传/列目录前自动创建（MKCOL 逐级），默认地址第一次用就能通；
- 「启用云同步」不再因为地址为空而失效。

## 手机端补齐与桌面端对齐的入口

- **立即同步**（谁新用谁：云端新就覆盖本机，本机新就上传，一样就跳过）；
- **恢复云端最新**（明确入口，点开选合并 / 覆盖，不用先刷新列表再猜哪行是恢复）；
- 上传后按策略清理旧备份：只删本机手动传的、保留最近 5 份，桌面传的与自动备份不动。
