# v0.1.74 — 今天三件套：打开就知道现在该做什么

> 主题：总览页信息不少（语录、生效规则、拦截记录），但以前回答不了最简单的三个问题：
> **现在在干嘛 / 今天到哪了 / 下一步点什么。** 这一版把这三件事放到最上面。

## 一、总览顶部：今天三件套

一条通栏，左中右三块：

| 位置 | 内容 |
|---|---|
| 左 | 状态点 + **专注中 / 休息中 / 空闲**；专注时显示「09:00–12:00 · 还剩 1:23」；空闲时显示「下一段 **14:00** 开始（2 小时 12 分后）」；今天没排就写「今天没有排时段」 |
| 中 | **今日自律时长 / 今日排班**（如 `1h20m / 3h`）+ 一条进度条 |
| 右 | 一个主按钮：专注时是「打开遮罩」，空闲时是「去排时段」 |

第二行是**这一段的目标**（0.1.73 的段目标），没写时是一行灰色提示。有打断时状态行后面挂一个琥珀色「被打断 2」。

## 二、一键开遮罩（开始零摩擦）

主按钮在专注时直接盖上遮罩，**用上一次选过的目标窗口**，不再让你重新选一遍。
只有两种情况会退回遮罩页：从没选过目标窗口（第一次总要选一次），或者那个窗口已经关了
——这时会明确告诉你原因，不会点了没反应。

## 三、实现要点

- 判定放 Rust（`focus::today_brief`）：下一段什么时候开始、今天排了多少分钟，
  必须和遮罩 / 锁机用**同一套排班口径**（`clock::plan_wins` 的窗口 from-to）。
  在 JS 里另算一份，迟早和判定打架。
- 20 秒缓存：`get_state` 每 1.5 秒拉一次，而这一块要读当天统计文件；
  写目标 / 改排班时立刻作废缓存，不会"刚写完要等 20 秒才看见"。
- 进度条只用「自律时长 / 排班时长」两个已有量，不引入新的口径。
