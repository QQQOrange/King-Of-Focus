# 0.1.90

修一个用户报的问题：**没开自律时段、只手动开专注遮罩时，遮罩上看不到「记一笔」（分心事件）按钮。**

## 原因

「记一笔」不是画在遮罩上的，它挂在**桌面 HUD** 上（HUD 是遮罩之上的一张小卡片）。
而 HUD 的显隐条件有两个：要有自律状态（规则 / 固化 / 专注段），并且遮罩不能开着。

所以"手动开遮罩 + 不在自律时段"这个组合，两个条件都不满足 —— HUD 被收起来，
`＋` 按钮也就跟着没了。可这恰恰是最需要它的场景：屏幕被盖住，突然想到一件事，
没有入口就只能记在脑子里。

## 改法

- **显隐**：遮罩开着、但不在自律时段里时，HUD 照样显示（这时它是唯一能记一笔的入口）。
  有自律时段 + 遮罩同时开着时仍然收起 —— 那时遮罩本身就是专注界面，再叠一块横条只是干扰。
- **层级**：遮罩线程把 HUD 当"自己人"。以前遮罩会把所有压在它上面的置顶窗口摘掉
  TOPMOST，HUD 会被按到遮罩底下；现在摘顶扫描跳过 HUD，并且每帧把它顶到遮罩之上
  （和放行程序、目标窗口的弹窗同一条通道）。HUD 同时进 `release_raised` 的保留名单，
  否则下一帧又会被打回非置顶，形成 8ms 级拉锯——那正是当初 lazytyper 弹条闪烁的原因。
- **文案**：这种状态下 HUD 显示「遮罩中 / 想到什么就点左上角记一笔」，
  而不是「专注中 / 00:00:00」——后者会让人以为在计时。
