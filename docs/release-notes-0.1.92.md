# 0.1.92 / Android 0.5.8

这一版是**功能审查**：不看安全、只看"这些功能到底跑不跑得对"。
四个方向（拦截引擎 / 统计积分 / 同步备份 / 命令层）各过了一遍，下面按用户能感知的方式列。

## 1. 统计的时长会莫名其妙变少

`stats::sample` 里那个"空闲回扣"计数器**一直坐在电脑前干活时也在涨**
（每秒 +1，只有"已空闲 60 秒"才清零）。于是连续用 2 小时、起身 61 秒，
它一次性把这 2 小时全扣掉——那条应用的今日时长趋近 0，报告、跨设备摘要、
HUD 的"今天已专注"全都跟着错。现在只扣"最后一次输入到现在"的那 60 余秒。

顺带补上曲线：回扣原来只动总数和小时桶，不动连续时段（spans），
会出现"这天写着 0 分钟、日历上却画着两小时色块"。现在一起裁。

## 2. 积分解锁之后仍然退不出去

README 写的是"解锁期间所有拦截暂停、可以退出程序、守护进程退出"，
但退出判定那条链从来没看解锁窗口——花掉积分照样弹"现在无法退出"。
两个入口（关窗口 / 托盘 / 热键共用的 `exit_blocked`，和强制退出的 `session_quit_locked`）
都补上。

## 3. 恭喜弹窗上的规则名是空的

结算那一刻，`active` 和 `lock_names` 刚被这一拍覆写成空，从它们拼名字永远是空串，
界面只好显示占位文案「自律自律规则」。现在整段持续记最后一次非空的名字。

同时"全程没有破功"改成真实计数：这一轮被拦了几次就写几次。

## 4. 若干"同一个东西两种口径"

- **手动遮罩**：统计把它算作"专注"，但总览 hero、状态条、报告说明都还说不算。
  统一成"算"，文案补齐。
- **规则自带的番茄休息**：以前不管这条规则到底会不会拦人，都算"休息中"——
  老配置里的规则番茄会在什么都没拦的时候拉起 HUD、记一段自律、结束弹恭喜。
  现在要求"专注段 + 规则立即生效"同时成立。
- **解锁期间能再买一次**：钱照扣，到期时间还可能被改短（买了 15 分钟，
  过 2 分钟再买 5 分钟，剩下变成 5 分钟）。已解锁中直接拒绝。
- **休息段点"用积分解锁"**：弹窗列出一堆价格，点了却报"没有正在进行的自律时段"。
- **两段式小时（wins）残留**：某小时里拖出过两段之后，右键「整小时」或改起止分钟
  会提示成功，但图和判定都不变。设置时清掉旧划分。

## 5. 同步与备份

- **云端文件读不懂就覆盖**：`updatedAt` 缺失/不是数字时原来当"最旧"，
  直接上传覆盖，用户零提示。现在报错并保持云端不动。
- **下载后重启会多传一次**：下载用的是 `save()`，它会把 `updated_at` 改成 now，
  磁盘比云端"新"而内存还是云端值，重启后判"本机更新"又传一遍。改用 `save_quiet`。
- **`last_sync` 记的是"上次尝试"**：断网/口令错也刷成"刚刚"，界面看着像同步正常。
  改成只在成功时前进。
- **测试模式串味**：备份目录和云同步都落在**正式**环境里（测试里点备份会写进正式
  备份目录并按份数删掉最旧的正式备份；测试里改设置会被自动同步传上去覆盖正式云端）。
  现在备份落在测试目录、三个同步入口都拒绝。
- **退出测试模式选「保留」会覆盖正式当天统计**：测试目录里那份"今天"只含测试的几分钟。
  现在按天**合并**（秒数、小时桶、标题、浏览器、时段都相加）。
- **手机往返把规则变空**：桌面一条默认形态的规则（黑名单 + 只填一个 exe）在手机绕一圈
  回来，apps 变成空数组——黑名单变成什么都不拦，白名单变成拦掉一切。
- **文件写坏**：配置、统计日文件、报告、账本、备份、游标全部改成"唯一临时名 + 改名"；
  账本读失败不再当成空账本覆盖。

## 6. 其它

- 质押结算先写 `stakes.json` 成功再加余额（写盘失败时原来每 20 秒重复返还），
  且只有奖励计入"累计获得"。
- 自定义统计区间起止填反时直接报错（以前静默显示 0）。
- 进统计页无条件重拉（以前早上看过的页面晚上还是早上的数）。
- HUD 的"待处理 N"跟着后端走（以前勾掉之后还显示旧数）。
- 报表 id 生成与读取统一过滤规则；统计清理终于会清账本目录。
- 锁定的开关不再"点击穿透"到编辑器；没被 catch 的失败会弹提示而不是静默。

## 已知未修

- 重启会丢掉"这一轮已专注多久"（`since` 是内存态；积分和统计是落盘的）。
- 周报/月报/年报只补最近一期，停几周再开会缺中间那几期。
- 备份载荷只是跨设备文档（规则/时段/积分/提醒/统计摘要），
  `Settings` 里遮罩、睡眠、HUD、语录等约 30 个字段不在里面；恢复是"部分恢复"。
- 改过备份口令之后，旧备份无法用新口令打开（没有"输入旧口令"的入口）。
- 备份口令为空时备份是明文（云端那份也是）。
- 手动遮罩期间的时长现在计入"专注"，但 `disciplineOn` 之外还有几处说明文案
  只列了规则/时段/固化。
