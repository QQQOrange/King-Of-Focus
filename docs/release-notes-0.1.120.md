## 覆盖率的实话

- 已包裹并全部有译文：**704 条**
- 仍未包裹：约 **1100 处**，其中绝大多数是**带插值的模板句**（`"还剩 ${x}"`）。
  这些不是漏掉，而是脚本刻意跳过的——它们要逐句改成 `Loc.isEn` 分支，
  属于下一轮的工作，不是"再加几条词典"能解决的。
- 剩余集中在：`GuardService`（117，通知文案模板）、`Portable/Model/Slots/CloudSync`
  （约 200，数据校验与错误提示）、以及各屏的插值句。

所以准确说法是：**所有"纯文案"已英文化，带变量的句子还没**。英文用户在设置/统计/
时段/规则/分心/锁机里看到的大面积是英文，但会零星遇到中文句子。
