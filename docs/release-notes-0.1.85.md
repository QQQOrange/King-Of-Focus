# 0.1.85 / Android 0.5.3

手机端最后两样补齐了：**周复盘**与**统计口径说明**。桌面端顺手给"试用结束"加了一句提示。

## 一、手机端：周复盘

设置 → 每周复盘。五个问题，每题前面挂着已经算好的数字，本周 / 上周可切：

1. 本周自律 `6h20m`，上周 `4h00m`。最投入的是 周三（`2h00m`）→ 「这周最好的一天是哪天？那天你做对了什么？」
2. 被打断 6 次，最多来自 Steam（4 次）→ 「下周要不要把它关掉？关不掉的话，替代办法是什么？」
3. 写了 6 个段目标：做完 3、一半 1、没做成 1、还没答 1 → 「是目标定太大了，还是时间选得不对？」
4. 记下 7 条分心事件，处理了 4 条 → 「还剩 3 条，哪一条值得现在就处理？」（旁边就是「去处理这 3 条」）
5. 质押结算 3 笔，干净跑完 2 笔，被没收 1 笔 → 「下周只改一件事——改哪件？」，提示写着"只写一件。写两件等于没写。"

一周从**周一**开始，与「时段」表横轴、统计页周视图完全一致——三处不一样的话，
用户看到"本周 6 小时"和时段表上的格子会对不上。

回答存 `kof/reviews.json`，按周存档、补齐五条、再存即覆盖。
读盘（七天日文件 + 账本 + 目标 + 质押）放在 IO 线程：主线程读会卡一下，而这一下正好落在"点进来"最敏感的时刻。

## 二、手机端：统计口径说明

统计页双轨 tab 右边一个小问号（26dp、压暗，必须"在但不抢眼"），点开是三段解释：

- **为什么分成两条轨**：三条判定条件（规则生效 / 在时段内 / 锁机中），两条轨绝不相加；
  「自律 2 小时」是"在自律状态下的使用时间"，不是"学了 2 小时"。
- **这些秒数怎么来的**：15 秒采样一次前台应用；量的是"在前台"不是"专注"。
- **离开的时间去哪了**：熄屏 / 锁屏 / 桌面 / 本软件自身都不计时——"看了两小时视频只记几分钟"最容易被误读的地方。

## 三、桌面端：试用结束说一声

向导里「先试 25 分钟」结束后会自己还原排班，但以前**没有任何提示**——用户只会觉得
"它自己坏了"。现在会说一句：「试用结束 · 25 分钟到了，已经还原你原来的时段」。
