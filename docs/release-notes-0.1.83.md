# 0.1.83 / Android 0.5.1

上一版把「目标」变成有结果的账，这一版把它**搬到手机上**，并给桌面补上"今日成果"。

## 一、手机端：上一段做到了吗

首页（状态卡下面、自律总开关上面）多一张卡：

```
上一段的目标
写完登录页
[做完了] [做了一半] [没做成]
```

点一下即记录，选中的变实心（绿 / 蓝 / 红），**再点一次撤销**。规则与桌面一致：
只挑"已经结束、写过目标、6 小时内"的那一段——早上那段到晚上还追着问，那不叫复盘。

数据存 `kof/intents.json`（`Goal` 加了 `state`）。改目标文案不会再清掉已有判定，
"写登录页"改成"写完登录页"不会把刚打的勾弄丢。

「分心事件」页的时段分组也跟着显示判定（"目标：写完登录页 做完了"），
让"原本要做什么 → 记了什么 → 做成没有"在同一处对得上。

## 二、桌面端：今日成果

总览三件套的进度条下面多一行：

```
1h20m / 3h
[=====        ]
4 个目标，做完 2 个
```

时长是过程，这才是结果。它和进度条并排，是想让人每天看到两个数：
**坐了多久**与**做成了什么**——这两个数不一致的时候，问题往往不在时长上。
