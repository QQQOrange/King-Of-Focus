# 0.1.108 / 插件 1.2.1 — 页面脚本的 CSP 修正

0.1.107 刚发就发现一个**会让功能静默失效**的问题，立刻修掉。

## 问题

插件 1.2.0 的页面脚本是靠往页面里插 `<style>` 来隐藏推荐流、给专注条上样式的。
但很多站点（X、GitHub 等）的 CSP 里没有 `style-src 'unsafe-inline'`，浏览器会直接
拦掉这段样式：

- 推荐流**看起来开了但没生效**；
- 专注条会变成一堆没有样式的裸文字挂在页面上。

更糟的是，控制台里只有一条 CSP 报错，用户根本关联不到插件头上。

## 修法

所有样式改走 **CSSOM**（`el.style.xxx = ...` / `el.style.setProperty(..., 'important')`）：

- CSSOM 不经过 CSP 的样式解析，任何站点都能生效；
- 推荐流用"逐个元素隐藏 + 记住原值"的方式，切路由或关掉开关时能**还原**，
  不会把页面永久改坏；
- 专注条的样式在创建元素时直接写上，不再依赖任何样式表。

## 顺手修的两处

1. **MutationObserver 可能把页面拖死**：X 那种页面每秒能触发几十次 DOM 变更，
   原来的写法每次都调一遍 `applyFeeds`。现在只在"该有的东西不见了"时才重跑，
   并且同一路径只跑一次（`feedKey`）。
2. **关掉开关不还原**：原来 `feedHide` 一关就直接 `return`，之前藏掉的容器
   仍然是 `display:none`，要刷新页面才恢复。现在会主动还原。
