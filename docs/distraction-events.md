# 分心事件（distraction inbox）

> 一句话：**想到什么，三秒内记下来，然后立刻回到原来那件事上。**
> 记录与处理是两件事，刻意分开——记录时不分类、不追问、不换页面；
> 处理时才有时段归属、勾选和提醒。

代码：`src-tauri/src/distract.rs`（判定与存储）、`ui/hud.js`（记一笔）、
`ui/app.js` 的 `viewDistract`（分心事件页）。数据：`king of focus data/distractions.json`。

---

## 1. 为什么有这个模块

专注被打断，多数时候不是因为"想玩"，而是因为**一个必须记住的念头突然冒出来**：
"等会儿要买牙膏""那个接口该加缓存""刚才那条消息还没回"。

大脑不会因为你决定"先不想"就放下它——它会一直占着工作记忆，直到你相信
"已经记在某个可靠的地方了"。所以这里做的不是"禁止分心"，
而是**给念头一个出口**：写下来，就等于告诉大脑"记住了，可以放下了"。

这也解释了为什么记录必须**极快**（HUD 上一个按钮 + 一个输入框 + 回车），
而处理可以**很慢**（事后逐条勾选、删除、变成任务）。

## 2. 记录：HUD 上的「＋」

- 位置：HUD 卡片四角之一，默认**左上角**，在「分心事件」页可改为其它三角。
  HUD 本身可以拖动，所以"位置"实际是两层：窗口放哪、按钮在窗口的哪个角。
- 只有模块开着（`settings.distract.enabled`）才出现；关掉后已记录的内容不受影响。
- 回车记下 → 输入框清空、面板不收起，可以连着记好几条（念头常常成串出现）。
- `Esc` 关闭；输入法组合中的回车（`isComposing` / 229）不当作提交。
- 记下时不问"这属于哪个任务"——问了就会打断，用户下次就懒得记了。

## 3. 归属：这条是哪个自律时段记的

每条事件都带 `segStart` / `segEnd` / `segLabel`：

- 「一段」= 相邻且都被选中的小时（`to == 60` 表示这一小时整段被选中）。
  09:00–12:00 排三格 = 一段；11:00 没选 = 断成两段。
- 判定在 `distract::segment_bounds`（纯函数，有单测）：往前/往后各最多并 24 小时，
  遇到空隙就停；11:00 那种半小时窗口（`to < 60`）自成一段。
- 不在任何时段里记录的，标为"不在自律时段内"，照样保存（有人就是会在自由时间想起来）。

为什么要归属：时段结束时要"汇总这一段"，报告里也要能说清"这条是那次坐下来时想到的"。

## 4. 处理：分心事件页

- 顶部：周视图 / 月视图切换、`‹ ›` 翻页、回到今天；右边显示当前查看的日期。
- 左：当天清单，**按时段分组**、组内按时间倒序；每条显示写入时刻 + 时段标签，
  左侧方框勾选，右侧删除。
- 右：日历（月视图 = 7 列日期格，有记录的点一个点，全部处理完变绿；周视图 = 7 张日卡），
  点任意一天立刻切换到那天的清单。
- 「清掉已完成」只删当天的已完成项——未完成的是"欠自己的账"，不给一键清空。

## 5. 提醒

| 时机 | 行为 |
|---|---|
| 自律时段结束 | 汇总本段未处理条数，弹一条通知（最多显示第一条内容） |
| 之后每 N 分钟 | 还有未处理项就再提醒一次，一次只提醒一条通知（含总数） |
| 超过 M 天 | 不再提醒（避免陈年旧账天天弹） |
| 关掉模块 | 只保留时段结束那一次也不发 —— 完全静默 |

参数在「分心事件」页可调：`remindMinutes`（默认 120，0 = 只在时段结束提醒）、
`remindMaxDays`（默认 7）。后台循环 20 秒一拍（`distract::start`），
用 `nudgedAt` 记录"上次提醒时刻"来保证间隔，而不是靠内存计时器——
重启程序不会把提醒节奏打乱。

「时段结束」的判据是 **时间**（`focusing` 从 true 变 false 且某条的 `segEnd` 贴近现在 ±3 分钟），
不用"当前是否有锁机遮罩"这类会被暂停改写的状态量。

## 6. 与遮罩的关系

「自律时段开始时自动开遮罩」= 遮罩配置里的 `followSchedule`，在这一页给了一个近路
（`distract_auto_mask` 命令），改完立刻 `mask::wake()` 重算，不用等下一拍。
默认值改为 **true**（新装即生效）；老配置里已经有这个字段，尊重用户原来的选择。

## 7. 边界

- **不进跨设备备份**：分心事件是"事件流"，跟统计一样，两台设备各记各的才说得通
  （在电脑前记下的想法，不该在手机上被提醒一遍）。
  `distract` 这组设置（开关 / 间隔 / 按钮位置）也留在**本机配置**里，不随 `.kofbak` 走——
  两端的"按钮"分别长在 HUD 和锁机遮罩上，位置选项本来就不是同一套语义。
- 单条上限 500 字，总量上限 5000 条；超量时只丢弃**最老的已完成**条目。
- 写盘走"临时文件 + 改名"，断电不会留下半截 JSON。
