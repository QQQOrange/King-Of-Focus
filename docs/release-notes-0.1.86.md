# 0.1.86 / Android 0.5.4

手机端补上「现在试 25 分钟」，两端终于一样了。

## 一、手机端：试 25 分钟

首页状态卡的积分下面：空闲时会出现

```
────────────────────
想现在试一下？
立刻跑 25 分钟：规则照常生效、锁机遮罩也会盖上来，结束后自动还原
                              [试 25 分钟]
```

点了立刻进入专注段，状态卡变成「专注中」+ 倒计时，底下一行写着
**「试用中 · 还剩 24:31，到点自动还原你原来的时段」**。到点自动还原并发一条通知。

正在自律段里没有这个入口——那会在"上一段做到了吗"里插进一段莫名其妙的记录。

### 怎么做到"不吃掉用户排班"（这块最容易做歪）

手机端没有桌面那套"多套方案"，所以试用只能**临时替换** `Config.days`。为了不弄丢原表：

1. 开始那一刻，把原始 7×24 表连同结束时刻写进 `kof/trial.json`；
2. 到点由服务每拍检查，把**那张原表**写回去（不是"清空重排"）；
3. **进程被杀也不怕**：`Store.init` 读配置之前先看试用状态，过期就当场还原。
   不做这一步，用户手排的时段就被永久换成了试用的那一小段。

试用期间用户改不了表：那会儿本来就处在专注段里，时段页是只读的（`ScheduleEngine.frozen`）。
