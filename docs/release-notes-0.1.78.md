# v0.1.78 / Android 0.4.9 — 花积分前先看清价格；被拦下时先看见目标

> 这一版是两处"少一次决策"的改动：一处让成本在点之前就可见，一处让拦截之后有出口。

## 一、积分成本前置（桌面）

以前「积分兑换」只写"×1.4 递增"，到底现在多少钱一分钟、还够买几分钟，得自己算。
现在直接写在卡上：

- 「今天第 2 次，单价 ×1.4 递增（第 1 次 15，第 2 次 21，第 3 次 29）」
- **「现在 21 分/分钟 · 余额够买 4 分钟」**（不够时写"还差 6 分才能买 1 分钟"）

解锁弹窗里，每一档旁边多一句「买完剩 X」/「还差 X」——买不起的档位不再只是变灰，
而是明确告诉你差多少。这样"算不清就随手点"会少很多。

## 二、拦截页显示段目标（Android）

轻档提示页（"这个应用现在不能用"）以前只有倒计时和"返回桌面"。现在在被拦下的那一屏
直接写出**这一段的目标**：

```
🔒 这个应用现在不能用
命中规则「娱乐」

这一段要做的是
把登录页写完

   12 秒后返回桌面
```

没写目标时换成一句「这一段还没写目标」，点一下回到主界面去写。

为什么这个位置重要：被拦下后的三秒是决策窗口。以前这里是"空白 + 倒计时"，
人最自然的反应是拿手机；现在这里摆着"你本来要做什么"，回去的概率明显更高。
