# v0.1.59 · 安卓统计页补上饼图 / 周月日历 / 明细列表（三块联动）

安卓 **0.3.6**。桌面端功能不变。

桌面统计页有三样手机端一直没有的东西：**饼图**、**周/月日历**、**按项列出的耗时明细**。
这一版把它们搬到手机上，并按手机屏幕纵向重排——不是把桌面那三栏硬塞进来。

## 新的页面结构（从上到下）

```
双轨 tab       自律时段内 / 时段外 / 汇总
视图 + 周期     [按日] [按周] [按月]     ‹ 10-31 周六 ›   今天
饼图            甜甜圈 + 中间合计 + 前 4 名图例
日历            按日 → 24 小时竖轨
                按周 → 7 列竖轨（每列一天）
                按月 → 7 列月网格（日号 + 总时长 + 横向 24 小时色条）
耗时明细        色点 · 名称 · 时长 · 占比 · 占比条（点开看连续使用段）
报告            累计 / 日均 / 最长的一天 / 用得最多（可复制、分享）
```

## 三块为什么必须联动

它们回答的是同一个问题——"这段时间我都在干什么"。饼图给比例、日历给分布、明细给清单。
所以周期只有**一个状态**（视图 + 锚点），三块都从它算：

| 操作 | 饼图 | 日历 | 明细 |
|---|---|---|---|
| 切「按周」 | 变成本周合计 | 变 7 列竖轨 | 变本周各项 |
| 点「‹ / ›」 | 换到上一/下一周 | 跟着换 | 跟着换 |
| 点月历某一天 | 变当日 | 变当日 24 小时竖轨 | 变当日 |
| 切「自律时段内」 | 只统计该档 | 只画该档的段 | 段也只取该档 |

以前只有饼图认档位、日历自己拼字符串，会出现"上面 3 小时、下面 5 小时"；
这次把三者收敛到同一个状态（与桌面 `statsTabKey()` 的单一来源思路一致）。

## 配色只有一个来源

与桌面同一组 12 色（`PALETTE`）。饼图前 8 名先占色，日历与明细沿用同一份映射
（`StatsCal.colorSlots`），所以同一个应用在饼图、日历、列表里永远是同一个颜色。

## 日历窗口（与桌面同规则）

- 一周从**周一**开始（和时段表一致）。
- 月视图**铺满整周**：`weekStart(1 号)` 到 `weekStart(月末)+6`，网格永远是 7 的倍数，
  不会出现"月末那几天挤成半行"；不在本月的日子淡化显示。
- 日均按**当月实际天数**算（31 天），不是按网格的 35 天——否则月末会把日均摊薄。

## 交互细节

- **点饼图某一块** = 选中这一项：明细里那一行加粗展开、日历里其他项淡化。
  点圆环之间的空洞不响应（手机上很容易点到中心）。
- **点周视图某一列 / 月视图某一格** = 进那一天（视图切「按日」），符合"从全局钻到细节"的顺序。
- **点明细某一行** = 展开连续使用段（`11:29–11:32 3 分`）。段按当前档位筛：
  选「自律时段内」时不会混进时段外的段。
- 翻到非今天时出现「今天」按钮，一键回来。

## 顺手修的三处

1. 明细的段以前无条件合并两轨，于是在「自律时段内」点开某项，明细里却是两档的段，
   和上面的总时长对不上。现在按档位筛（汇总才合并）。
2. 报告文本的缓存键少带了区间，翻页后报告还写着前一天（`10-31` 显示成 `10-30` 的内容）。
3. 已选单档时，饼图下方那句"自律时段内 X%"和报告里的"其余 N"都没有意义（那是汇总口径），
   现在只在「汇总」显示。

## 验证（AVD kof35，灌了 20 天样例数据）

| 场景 | 结果 |
|---|---|
| 按日（10-31 周六） | 2 小时 12 分；Chrome 61% / Messages 38%；时间轴与明细一致 |
| 切按周 | 17 小时 2 分、日均 2 小时 26 分、生效中 25%；7 列各带当日合计（3.0/3.8/1.5/3.7/2.9 时） |
| 切按月 | 51 小时 23 分、日均 1 小时 39 分（÷31）；7 列网格、日号 + 3.9时 等 |
| 点月历「20 日」 | 直接进 10-20 当日；出现「今天」按钮 |
| 切「自律时段内」 | 当日 45 分钟（Chrome 88% / Settings 11%），日历只画该档 |
| 点饼图环上一点 | 明细对应行展开，列出 3 段 |
| 点明细行 | `共 56 段，合计约 32 小时 8 分`，逐段 `10-12 09:00–09:40 40 分` |
| 翻页 | 报告日期跟着变（10-30 – 10-30） |

单测：Android **146 条**全绿（新增 11 条：周/月窗口、整周铺满、两轨合并、切片与「其他」、
配色沿用、同一天条目排序、按档筛段）；桌面 Rust 241 / UI 1032 / i18n 656 全过（桌面未改）。

## 没搬的

桌面饼图的**引导线标签**与**悬停高亮**、日历的**跨天拖动选择**都依赖鼠标与宽屏。
手机上换成：图例代替引导线、点选代替悬停、点格进当日代替拖动。
