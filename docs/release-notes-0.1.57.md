# v0.1.57 · 安卓端「自律时段」按桌面端重做

安卓 **0.3.4**。桌面端功能不变，版本号跟着发布走。

以前手机和电脑对"一段时段"的理解不一样：手机只有"这小时选没选"，
于是两端算出来的自律时间、番茄相位、"停止本段"的作用范围全对不上。
这一版把桌面端那套语义整体搬过来，并补上两处只在桌面上有的保护。

## 一、段（seg）：相邻不等于同一段

| | 以前（手机） | 现在（与桌面一致） |
|---|---|---|
| 相邻两段 | 时间贴合就并成一段 | 各有自己的 `seg`，**不会**被并 |
| 一小时里两段 | 只能存一段，第二段把第一段撑成整小时 | `wins` 存多段（09:00–09:30 + 09:45–10:00 各自独立） |
| 一次拖选 | 每小时各自成段 | 整次拖动共用一个 `seg` = 一段 |
| 紧挨已有段再点一格 | 并进去 | **新的一段** |
| 停止本段锁机 | 按"连续几个小时"算 | 按段身份算：停了这一段，下一段照锁 |

判定出口只有一个：`Slots.windowsOf()`。老配置（没有 `seg`、没有 `wins`）退回
"按连续性合并"，所以升级不会把已有排班打碎。

## 二、通用番茄时长只影响新选的时段

以前改「专注 45 / 休息 15」会把**整份方案**重排——用户只是想把默认值调一下，
结果所有手调过的小时被一起抹平，还没有任何提示。

现在与桌面端一致：默认值只决定"之后新选的时段用什么节奏"，已排好的小时各自保留。
要统一改，用新加的 **「应用到已选时段」**（会二次确认，写明会影响多少个小时，
并且跳过已经过去/锁住的星期）。

## 三、每套时段可以挑「管哪些自律规则」

桌面端 `ClockProfile.bound` 搬到手机上：时段页新增一排芯片，
选「全部」= 全部生效（老配置语义），或勾具体分组。

于是「工作日那套只管工作类、周末那套只管娱乐类」可以在一台手机上共存，
换方案 = 换时间表 + 换管辖范围。

## 四、专注段生效中，时段页只读

这是桌面端早就有的保护（`settingsFrozen`），手机之前没有：
自律期间能改表，锁机就只是建议。

现在专注段里：网格不吃手势、方案不能增删改、绑定与番茄默认值都点不动，
顶部有一行红字说明。三个出口照旧可用——**积分解锁 / 暂停锁机 / 停止本段**，
它们都是用户明确付过代价的，所以不冻结。

## 五、方案管理补齐

- **复制这套**：连排班带番茄时长带规则绑定一起复制，切过去即可改（桌面 `clockProfDup` 同义）
- **新建 = 空表**：以前是复制现有排班，还得一格一格擦掉
- **上限 12 套**，与桌面端 `CC_MAX_PROFILES` 一致

## 六、备份互通

- 导出**全部方案**（以前只导当前这一套），带 `bound` 与每段的 `seg`
- 覆盖导入按桌面端的 `clock.profiles` 数组整套接受；文档里没有方案数组时只换当前这套，
  不会把本机其它方案删掉
- 顺手修掉一个真 bug：导出时 `bound` 被后面一行 `put("bound", [])` 覆盖，**永远是空**

## 验证（AVD kof35）

| 场景 | 结果 |
|---|---|
| 一小时两段（0–30 与 45–60） | 配置与判定都保留两段，中间 15 分钟不算选中 |
| 紧挨已有段点一格（11:00 补在 11:15–12:00 前） | 变成两段，不同 `seg`，没合并 |
| 长按 13:00 拖到 14:15 | 跨两小时共用同一个 `seg` |
| 在格子上直接滑 | 只滚动（网格动了 1 小时），数据一分不变 |
| 改通用时长 50→49 | 已选的 45/15 保持不变 |
| 「应用到已选时段」 | 今天已选的 2 小时改成 49/10；锁住的周一不动 |
| 绑定「娱乐类」 | 只写进当前方案（`bound: [r-yule]`），另一套不受影响 |
| 复制这套 / 新建 / 删除 | 副本连 bound 一起复制；新建是空表；删除回到上一套 |
| 专注段内点格子、点复制 | 都不生效，顶部红字可读 |
| 积分解锁后再点同一格 | 立刻生效（证明拦截来自冻结，不是点空了） |

单测：Android **118 条**全绿（新增段身份、`to=0` 整点、`retime`、绑定筛选、冻结、备份往返）；
桌面 UI 断言 1032 条、i18n 656 条全过（桌面代码未改）。

## 没搬的

桌面端可以**拖动已有段平移、拖边缘缩放**。手机上这套手势已经有"点起点 → 长按 → 拖选"，
再叠一个"拖已有段 = 平移"会互相打架，所以这版没做；要改时间还是重画一段。
