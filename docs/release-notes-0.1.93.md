# 0.1.93

把上一版"已知未修"里列的几件全部做完了。

## 1. 备份现在是**完整**备份

本地备份的载荷原来只是跨设备文档（规则 / 时段 / 积分 / 提醒 / 统计摘要），
`Settings` 里遮罩、睡眠、HUD、语录、浏览器路径、开机自启等约 30 个字段根本不在文件里。
用户在设置里看到「备份」，自然会以为全都备了——换台新机恢复才发现少一半。

现在备份里多挂一个 `native` 段（整份配置）：

- 恢复时以它为底，**整份还原**；
- 机器专属项（同步账号、更新令牌、提权、自启）和备份口令仍听这台机器的；
- 手机端不认识这个键，会原样忽略——跨设备往返的行为完全不变；
- 两端的"字段签名"自检比对的仍是跨设备文档本身，加了这一段不影响对齐。

## 2. 改过备份密码之后，旧备份能恢复了

备份是用**当时设置里的**密码加密的。改过密码后，旧备份只会弹
「密码不对，或者备份文件被改动过」——文件明明是好的，而且没有任何地方能输入旧密码，
唯一出路是把设置里的密码改回去，之后所有新备份又都变回旧密码。

现在三个恢复入口（本地 / 从文件 / 云端）都接受一个临时口令：解密失败时弹一次输入框，
用那个密码解开并恢复，**不会**改动你当前设置里的密码。

顺便把"没设密码 = 备份是明文"做成设置页里一条常驻警告。

## 3. 重启不再丢"这一轮已专注多久"

计时起点一直是内存态：重启后 HUD 的已专注时长归零，恭喜弹窗也只算重启之后那一段
（积分和统计是落盘的，只有它没有）。现在每 20 秒存一次，启动时按"停机时长"把起点往后挪——
停机那段时间不计入专注时长，会话结束就清掉。

## 4. 周报 / 月报 / 年报 / 自定义周期会补齐中间那几期

原来只生成"最近一期"：一周不开机，中间那几周永远不会生成，
而界面上写的是"下次启动会补齐"。现在按游标逐期补，某一期写盘失败就停在那期、下次再来。

## 5. 守护进程改成改名副本运行

守护和主程序共用映像名，一句 `taskkill /F /IM "King Of Focus.exe"` 就能把两个一起杀掉，
"杀不掉"这件事就没了。现在把主程序复制成数据目录里的 `kof-guard.exe` 再从那里启动
（主程序升级后自动刷新副本），主程序路径通过 `--main-exe` 传进去——否则守护复活时
会把自己当主程序拉起来。复制失败（权限 / 杀软）时退回原样：宁可共用映像名，也不能没有守护。

## 6. 口径文案

统计页「为什么分成两条轨」和导出报告的说明补上"手动开着专注遮罩"，
与 `state_on` 的实际判定对齐。
