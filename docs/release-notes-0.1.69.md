# 0.1.69 / Android 0.4.5

## 云同步范围补齐：日程 + 规则 + 统计摘要

以前 `.kofbak` 只带规则与时段，**统计完全不带**；而且桌面「立即同步」只传它自己的
`king-of-focus.json`，手机读不懂 —— 等于"桌面点同步，手机看不到"。

现在一条通道传全：

| 段 | 内容 |
|---|---|
| `clock` | 时段方案（7×24 排班、专注/休息、**每小时休息上限**、方案绑定的规则分组、刻度、总开关） |
| `rules` | 规则（黑白名单、网站、绑定的自动启动） |
| `points` | 积分与解锁到期 |
| `settings` | 语言 / 主题 / 提醒 |
| `stats`（新） | **统计摘要**：每天总时长、自律时长、前 3 个应用（30 天，约 3 KB） |

- 桌面「立即同步 / 上传本机」现在**顺带传一份 `.kofbak`**，手机点同步就能拿到；
  附带备份失败不影响配置上传，结果里会注明。
- 统计摘要**分设备存**、单独展示，不与本机统计相加（手机 3 小时 + 电脑 8 小时没有意义）。
- 桌面统计页与手机统计页都多了一行「另一台设备：最近 7 天总 X · 自律 Y」。

## 冲突规则

- 配置：`updatedAt` last-write-wins（差 2 秒内视为同版本）。
- 恢复：覆盖 = 整体替换；合并 = 规则只加、时段只补空小时、积分取大。
- 摘要：空的不收、旧的不收、自己导出的不收（不会在"另一台设备"里看到自己）。

## 已知边界

规则里的**应用条目**跨不了平台：桌面按 exe 路径、手机按包名。桌面条目会落在手机的
"桌面专属"（`foreign`）里原样带回，不会硬塞进包名名单。时段、积分、提醒、规则结构本身完全一致。

详见 `docs/sync-scope.md`（数据范围 / 触发时机 / 冲突处理 / 验收表）。
