# 0.1.89 / 插件 1.1.2 / Android 0.5.7

这一版是**修 bug**：五个方向的并行复核（核心拦截链、数据持久化、本地接口与插件、
前端、命令层/遮罩/退出）挑出 90 多个问题，按"能丢数据、能被绕过"优先修掉了其中的大部分。
下面按用户能感知的方式分组，每条都写了"以前会怎样"。

## 1. 能丢数据的

- **读配置失败会覆盖真实配置**。`config.json` 被占用（杀软/网盘/编辑器）、权限不足、
  编码异常时，原来一律当成"没有配置文件"并立刻写回默认值——规则、积分、备份口令、
  更新令牌全没，而且连留档都没有。现在只有"文件不存在"才写默认值，其余情况先留档
  `config.unreadable-<时间>.json` 且绝不回写。
- **统计日文件读失败会变成"这天零使用"**。跨天轮转和 flush 会把这份空对象写回同名文件，
  那天的数据就真没了。现在读失败先改名留档，改不动就整次跳过写盘。
- **记账写入伪造 `updatedAt`**。保存配置时无条件刷新时间戳，连"上次同步时间 / 检查时间"
  这种记账写也刷新，于是本机永远"比云端新"——另一台设备刚上传的规则，这边重启一次就被
  过期配置覆盖。新增 `save_quiet()`，四处记账写入改用它。
- **云同步上传后把旧快照写回**。上传可能跑好几秒，期间改的设置、刚赚的积分、刚买的解锁
  会被上传前的快照覆盖。现在上传成功后重新读一次当前配置再落盘。
- **加积分与保存配置打架**。`add_points` 是"读-改-写"且中途放锁，并发保存会吞掉刚加的积分
  （反过来也会吞掉用户刚改的设置）。现在整段持有写锁。
- **跨设备备份只认标记就能恢复**。`{"kof":"king-of-focus"}` 也能解析成一份空文档，覆盖模式
  会把规则、时段、积分全部清空。现在要求 `format` 匹配、`schema` 在范围内、且至少带一个
  有效分区。
- **合并备份时积分和对方统计被静默丢掉**。"什么都没变"只比了规则条数，而合并还会带走
  积分（取两边较大）和另一台设备的统计摘要。现在这两项也算进"有没有变化"。
- **恢复旧备份会关掉提权 / 改写开机自启**。这两项是"这台机器怎么运行"，跨机恢复不该覆盖。
  和云同步下载保持同一套保留规则。
- **报表游标在失败时也前进**。周/月/年/自定义报告生成失败（磁盘满、路径不可写）后仍被标记
  成"已生成"，以后永远不再补。现在和日报一样，只有写成功才推进。

## 2. 能被绕过的

- **新手引导是一条后门**。设置页随时能重走一遍，点「完成」直接换掉正在生效的排班
  （还把规则换成非固化），硬锁三下就没了。现在要过纪律校验和固化锁。
- **改"段尾那一格"能提前结束整段**。校验只比了当前这一小时的开关和时长，而格子菜单是按
  单个小时改的：把 09:00–12:00 那段的最后一格 `to` 改小，11:01 之后自律就结束了。
  现在直接比"这一段什么时候结束"，不允许提前。
- **更多"改松"没人管**：固化 `true→false`、只允许→只拦截、把已有条目的拦截目标换掉
  （id 不变）、调大当前小时的休息上限、关掉浏览器巡检。都在自律时段内锁住了。
- **一键关掉所有拦截**：演练模式、浏览器守护、禁止任务管理器、网页被拦关浏览器、
  先温和关闭，以及往「全局保护名单」里加进程名。以前这些在时段内随便改、还提示"已保存"。
- **固化期间照样能改设置**：遮罩参数、快捷键、跟随自律、媒体管控、提醒、HUD 各写各的
  配置，从不查锁。现在统一走 `deny_if_locked`。
- **测试模式的门禁用错了判据**。原来用"能不能退出"，而它默认放行，休息段就能溜进去把规则
  关掉；`keep=true` 退出时还会把改松的配置整份盖回正式环境。现在按"在不在自律时段"判。
- **`apply_rules=false` 时"什么都不拦，但不许走"**。锁定只看专注段，拦截还要求"时段内让规则
  立即生效"，两者不一致。

## 3. 安全

- **`open_url` 是活的命令注入**。`cmd /C start "" <url>` 里 cmd.exe 照样解析 `& | ^`，
  一条带查询串的正常链接都会被拆成两条命令。改走 `ShellExecuteW`。链接来源包括语录源首页、
  自动打开的目标、以及从备份/云端恢复的配置。
- **固化提示卡存储型 XSS**。规则名未转义就拼进 HTML，而通知窗是 `innerHTML` 渲染、
  webview 又是 `withGlobalTauri` + `csp: null`——一份构造过的备份就是完整 IPC 权限。
- **本地接口对任何网页开放**。一句 `fetch('http://127.0.0.1:27315/api/heartbeat')` 就能让
  浏览器守护以为插件在跑，整道防线失效；`/api/report` 还能刷通知抢焦点、`/api/elevate`
  能触发 UAC。现在 CORS 只精确回显扩展来源，会改状态的接口校验 `Origin`。
- **自动更新会执行任意路径**。只判"文件存在"就把调用方给的路径拼进 `.cmd` 以管理员身份执行。
  现在要求父目录必须是下载目录、扩展名是 exe/msi。

## 4. 承诺了但没做到

- **番茄休息被当成自律结束**。每进一次休息就弹一次"本轮完成 · 全程没有破功"、把主窗口
  强行拉到前台、HUD 收起、已专注时长清零。README 写的是休息时 HUD 显示"休息中"、
  整段结束才恭喜。
- **积分解锁没有真的暂停**。遮罩停了，但任务管理器照杀、浏览器巡检照关，而且解锁期间还在
  按分钟发积分（花积分买的自由时间变成刷分）。
- **三条退出路径跳过清理**：以管理员重启、`/api/elevate`、自动更新只停了守护就退出，
  被遮罩抬升/摘顶的第三方窗口永久留着、暂停过的媒体不恢复。现在统一走完整清理链。
- **演练模式对插件无效**。`dryRun` 从没导出，界面写着"只记录不真的关闭"，插件照关。

## 5. 误杀与卡顿

- **浏览器守护把 Firefox 也关了**。Firefox 装不了 Chromium MV3 插件（界面一直标注
  "只识别、不拦截"），但守护按进程名列表关人，自律时段里用它就会每轮被杀。
- **"判定不出来"被当成"没装插件"**。自定义 `--user-data-dir`、首次运行还没生成配置档、
  Preferences 正被写时读不到扩展列表，原来 1.2 秒后就把浏览器关掉。新增 `unknown` 状态，
  守护对它放行，界面显示「状态未知」。
- **更新下载被 60 秒总时限掐断**。`timeout(60s)` 在 ureq 2.x 是**整个请求**的截止时间，
  48MB 的安装包要 800KB/s 才赶得上。下载改用 30 分钟总时限 + 60 秒单次读。
- **统计区间没有上限**。`stats_range` 的区间直接来自界面参数，一个超大区间就是几百万次开文件
  且在 UI 线程上跑。现在和日历一样钳到 366 天。
- **拦截失败每秒刷一条事件**。结束失败（目标以管理员身份在跑）时每一拍都记一条，
  "已拦截 N 次"跟着疯涨。现在失败也走 5 秒节流。

## 6. 插件

- **一条坏规则废掉整套 DNR**。指纹先置位再写、没有 try/catch，而 `localhost:3000`、
  中文域名这类条件会让 Chrome **整批**拒绝——之后指纹永远对得上，DNR 再也不重建，
  只剩 4 秒一次的 JS 清理在兜。现在逐条校验 + 失败降级逐条写 + 写成功才记指纹。
- **DNR 与 JS 判定分叉**：正则不锚定（`?q=youtube.com/x` 也被拦）、`#` 未剔除
  （`a.com/#/x` 在 DNR 不命中而 JS 整域拦）、白名单兜底优先级低于黑名单例外。
  统一成：锚定 `^https?://(?:www\.)?`、剔除 `#`、优先级 50/45/40/25/20。

## 7. 界面

- **英文界面下所有弹窗都是中文**。`I.apply` 只在启动和切语言时对 `body` 跑过一次，
  之后弹窗是直接 `innerHTML` 插进去的。现在弹窗插入后跟一次翻译。
- **保存被拒还提示"已保存"**。`saveConfig()` 只返回成败不抛异常，而十几处写法是
  `try { await saveConfig(); toast('已保存') } catch`——固化拒绝时先弹红错、紧接着弹成功。
  统一改成 `if (!(await saveConfig())) return;`。
- **取数据失败被缓存成"这天零使用"**。一次 IPC 失败就让日历显示"没有使用记录"，
  而且缓存让后面永远不再重试。现在失败不入缓存、画"读取失败，正在重试…"并自动重试。
- **与后台失联时界面继续装正常**。轮询失败只写了 console，状态条还画着上一份快照。
  连续失败两次就在状态条上明说"与后台失联，正在重连…"。
- **删语录来源报错名字**。`splice` 之后才取名字，删「一言」会提示"已删除来源「内置精选」"。
- **「自动同步」开关从不落盘**，1.5 秒后就被刷回旧值。
- **英文时长显示漏中文**（"合计 1 小时 05 分"）。
- **关掉一个被覆盖的规则编辑器后总览不再刷新**（`S.editing` 没清）。
- **遮罩的"被摘顶窗口"列表无上限、且按裸句柄还原**。句柄被系统复用时，退出时可能把另一个
  进程刚创建的窗口顶到最前面。现在记 `(hwnd, pid)` 并限制条数。
- **前一条通知会把后一条提前收走**（每条通知一个定时线程，到点无条件 hide）。

## 已知未修

- `taskkill /F /IM "King Of Focus.exe"` 会连守护进程一起杀掉（两者共用映像名）。
  彻底解决要改成"从数据目录里的一份改名副本运行守护"，改动面大、做错会让守护完全失效，
  留到下一版。
- 守护被反复杀死时的"40 次后放弃"只在单个守护进程内生效，主进程会重新拉起一个新的。
- 拿不到进程映像路径时一律视为"受保护"（避免误杀系统进程），因此这类目标不会被拦截。
