## 又踩到一个，这次是 Kotlin 的插值边界

`Loc.p("…${s.bestDayLabel.ifBlank { \"—\" }}…", "…${…ifBlank { "—" }}…")`
——在 `${ }` 里面 Kotlin 是**按代码**解析的，`\"` 在那里不合法。
正确写法要么保留嵌套字符串原样（不能被外层引号转义），要么先把值算出来放进变量。

处理：`ReviewScreen.kt` 整份还原，**这 8 条留到下一批**，改用"先算变量再拼"的写法，
避免和外层字符串的引号打架。其余六个界面已编译通过。
