# 0.1.81

这一版补的是**第一次打开软件的那五分钟**。

## 一、首用向导（三步）

以前装完是"空"的：十几个页面每个都能点，但不知道先做哪一件。多数人在这一步就
卸载了——不是功能不够，是不知道从哪开始。

现在新装第一次启动会直接弹出来，一次只问一件事：

**① 你打算什么时候学？**
七个星期按钮（默认工作日）+ 起止小时（默认 20:00–22:00），下面实时算给你看
「工作日 20:00–22:00 · 每天 2 小时」。提示语写的是"先选一个你真能做到的时间——
小一点没关系"。

**② 这些时候，哪些不该打开？**
直接列出**当前打开的程序**（读不到就说明原因，并告诉你可以跳过），点一下勾上。
自家的进程不会出现在名单里。这一步可以全跳过。

**③ 就这样，可以开始了**
一张摘要：每周约几小时、挡住几个软件、到点自动打开遮罩（开）。两个出口：
「完成」和「先试 25 分钟」。

三条都落到**既有结构**里，不新造一套数据：时段就是「自律时段」页里的那套方案，
规则就是「自律规则」页里的那一条；以后想改不用另找地方。重走一遍只会覆盖向导
自己写的那一套，不会动你手调的时段和规则（设置 → 新手引导 → 重新走一遍）。

## 二、"先试 25 分钟"是真的 25 分钟

不是演示、不是截图：它现在写一套**一次性时段方案**（从当前这一分钟起 25 分钟），
到点由后台每拍自动删掉并把原来生效的方案还回去；程序关掉再打开也能收干净——
因为清理由循环里的 `tick_trial` 做，不依赖任何定时器。

这是我没有偷工的地方：为了"试用"就永久改掉用户排班的做法，本质是 bug。

## 三、老用户不会被弹

配置里 `onboarded` 是 `Option<bool>`：

- 老配置里没有这个键 → `undefined` → **视为已走过**，不弹；
- 新装（`Config::default`）→ `Some(false)` → 启动时弹；
- 走过 / 跳过 → `Some(true)`。

顺手把"到点盖遮罩"（`mask.follow_schedule`）在向导里一并打开——不打开的话，
用户排完班等着看效果，却什么都不会发生。
