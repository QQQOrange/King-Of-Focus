# 0.1.112 — 关闭遮罩后 HUD 立刻收起

## 现象

关掉遮罩之后，HUD 那条悬浮小窗还留在屏幕上，要等一会儿才消失——如果扫描间隔调大了，
就是好几秒。HUD 是置顶窗口，多留一秒就一直压在其它窗口上面。

## 原因

HUD 的显隐由监控线程每 `poll_ms` 一拍算一次（默认 0.8 秒，可在设置里调到 5 秒）。
`mask_stop` 只改了遮罩状态本身，没有顺手处理 HUD，所以"关遮罩"和"HUD 收起"之间
隔了一个扫描周期。

## 修法

`mask_stop` 里立刻按当前状态决定 HUD 去留，同时叫醒遮罩线程收掉覆盖层：

```
session_on = 有生效规则 || 固化锁定 || 专注段 || 番茄休息
if !session_on { HUD.hide() }
```

判定**和监控线程那段保持完全一致**，不是图省事一律隐藏——自律生效中 HUD 是专注状态条
（剩余时间、这一段被打断几次），那时它本来就该在。

## 验证方式

1. 退出重开（0.1.112）。
2. 确认当前**不在**自律时段、也没有规则生效。
3. 打开遮罩 → HUD 出现（为了「记一笔」）→ 关闭遮罩。
4. HUD 应当**立刻**消失，不再等下一拍。

如果这时 HUD 仍在，说明当时确实有规则/时段在生效（那种情况 HUD 是设计上要保留的），
把"当前状态"那一栏截图给我，我按实际状态再判断。
