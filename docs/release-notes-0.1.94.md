# 0.1.94

这一版只做一件事：**把文档补上**。README 和软件里的「帮助」页都停在几个月前，
写着已经不存在的功能，也让新功能无处可查。

## README（项目主页）

- **版本号从 `0.0.1` 改成 0.1.94**（三端都写清楚）。这一行之前一直没跟着发版走，
  点进项目主页第一眼看到的就是个假版本号。
- **§1 规则的生效逻辑**整段重写：规则**不带时间表**，什么时候算自律时间由「自律时段」决定。
  原文写的是"时间 ∈ 规则的时间表 → 生效"，和现在的引擎完全相反。
- **§6 番茄休息**重写：番茄在「自律时段」里按小时配，休息段内**所有**规则暂停；
  规则上那个旧的「休息」标签已经移除。
- **§8 桌面 HUD** 补上手动遮罩时的秒表形态（遮罩中 / 本次已开多久 / 今天已专注多久 /
  90 分钟提醒）、「记一笔」、以及"重启不丢已专注时长"。
- **新增 §10 备份与恢复**：说明 `.kofbak` 的两层结构（跨设备文档 + `native` 完整配置）、
  覆盖/合并的差别、哪些东西永远听本机的、改过密码怎么用旧密码恢复、云端与手机互通。
- **§五 两种状态**补上"手动开着专注遮罩也算自律开启"，并说明理由。
- **§四 数据位置**补上备份目录、`session.json`、`kof-guard.exe`、`test/`。
- **§七 已知限制**更新：测试模式用独立数据目录、HTTP 服务的 `Origin` 校验、守护副本依赖可写目录。
- 「三步开始」的第三步改成"先在「自律时段」排时间，再建规则"，和现在的界面一致。
- 顶部功能表补一行「备份」。

## 软件内「帮助」页

- **§2 自律规则与生效**：改成"一条规则 = 一份名单，不带时间表"。
- **§3 番茄与提醒**：改成按小时配番茄、休息期间所有规则放开。
- **§7 专注遮罩**：补上手动遮罩时的 HUD 秒表与「记一笔」。
- **§8 统计与报告**：补上"自律开启"的四个口径（含手动遮罩）、离开 60 秒不计、
  停机几周后中间那几期会一次补齐。
- **§9 备份与云同步**：改成完整备份、旧密码恢复、明文警告。

帮助页的英文译文同步补齐（`check_i18n` 749 条 100%）。
