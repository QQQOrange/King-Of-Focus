# 0.1.121 / Android 0.7.5 — 英文界面：带插值的句子（第一批）

## 新增机制：`Loc.p(英, 中)`

带变量的句子不能查词典，也不该改成格式串：

```kotlin
Loc.p("Locked · ${left}", "锁机中 · ${left}")
```

为什么不做 `%s` 格式串：Kotlin 模板里可以放任意表达式（`${ScheduleEngine.fmtLeft(x)}`），
改成格式串要把参数一个个提出来；而且中英语序不同，一旦语序不一样就得重排参数——
那是最容易出错的地方。两份成品并排摆着，翻译对不对一眼能看出来。

## 一个教训：脚本把文件改坏了

第一版替换脚本的正则用了 `[^"\\]` 来匹配字符串内容——**它会把换行也吃进去**，
于是一次匹配跨了十几行，把 `SettingsScreen.kt` 里的 `canShowDialog`、`capsOf`、
`KeepAliveSection` 三个函数整个吞掉，编译器报"未解析的引用"。

定位方式：编译报"某函数找不到"，但那函数在文件里明明存在 → 说明结构被破坏。
处理：`git checkout` 还原该文件，正则补上 `\n` 排除项后重跑。

设置页这 23 条因此**没有进这一版**（其余文件已通过编译与测试）。留到下一批，
用同一条修正后的规则处理。
