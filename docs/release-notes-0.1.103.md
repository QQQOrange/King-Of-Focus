# 0.1.103 — 把这套东西变成"出问题能查、窗口位置能记住"

这一版没有一个新功能，全是**替用户想到**的那类改动：不主动做，用户可能一两年都不会提，
但真出事的时候，有没有这些东西差别很大。

## 1. 运行日志 + 崩溃快照

这是个 `WinExe`（没有控制台），`eprintln!` 谁都看不到；`panic = "abort"` 让崩溃直接
消失、不留痕迹。于是"它有时候自己退出 / 规则突然不生效"这类反馈，手上能查的东西是**零**。

现在：

- `king of focus data/logs/app.log`：启动（版本 / 权限 / 数据目录）、配置解析失败、
  检查更新结果、云同步错误、导出诊断、正常退出……都按 `时间 [tag] 内容` 记一行。
- 超过 1.5MB 自动滚成 `app.1.log`，不会无限长大。
- 装了 panic 钩子：崩溃时写 `crash-时间.txt`，带 backtrace，然后才退出。

## 2. 「关于 → 诊断信息 → 导出」

一键生成一份文本，内容是**排障真正需要的**，不是整份转储：

版本 / 系统 / 架构 / 是否管理员 / 是否测试模式 / 数据目录 / 端口 ·
当前自律状态、命中规则、固化、番茄、今日拦截数、积分 · 云同步开关与上次结果/错误 ·
更新通道缓存的三端版本 · 最近 400 行日志 · **脱敏后**的配置

网盘账号密码、备份口令、GitHub 令牌一律替换成「••••（已隐藏）」——
用户把这份文件发出来时不会顺带泄露凭据。

帮助页新增「11 · 出问题了怎么反馈」，把上面这些写成用户看得懂的三句话。

## 3. 主窗口位置和大小会被记住

以前每次启动都是固定初始位置：放在副屏上的人，每次开机都要再拖一次。

现在按窗口存 `king of focus data/window.json`（**不进同步配置**——窗口几何属于
"这台机器、这块屏"，同步过去只会在另一台机器上把窗口摆到屏幕外）。

两个细节：

- **越界校验**：拔掉副屏之后，存下来的坐标可能落在所有显示器之外，窗口会"消失"
  （任务栏有图标，点了不出来）。恢复前用显示器矩形核对，越界就只恢复大小并居中。
- **最大化**：最大化时不覆盖已存的宽高，只记 `maximized`，取消最大化才能回到原来的大小。

配了 4 条单测（屏幕内 / 完全在外 / 只露标题栏一角 / 副屏坐标），`cargo test` 289 → **293**。

## 4. 报告目录不再无限增长

每生成一份报告落一个 json，日报一年 365 份。现在只保留最新 **200** 份（按修改时间删旧），
列表不会越开越慢。
