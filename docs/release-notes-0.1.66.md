# 0.1.66 / Android 0.4.3

## 安卓更新通道与桌面端对齐

手机端现在能完整走完「检查 → 下载安装包 → 校验 → 调系统安装器」，
并且可以填 GitHub 个人访问令牌：

- 匿名调用 GitHub API 每小时 60 次，共享网络很容易被用光（表现为 403）；
  填了令牌是 5000 次/小时。
- 令牌只发给 `api.github.com`：清单与安装包走的是公开下载地址，不带令牌。
- 只保存在本机——不进备份、不进云同步、界面永不回显（暗文 + 只显示"已设置"）。
- 出错时分开说：令牌失效（401）与配额用尽（403）是两句不同的话，不再只甩一个 HTTP 码。

## 设置 → 版本与更新 新增

- **GitHub 个人访问令牌**输入框（暗文）+ 保存 / 清除 + 「怎么获取？」跳官方文档；
- **API 配额**一行：剩余 X / 上限 Y 次（每次检查更新时一并查询）；
- 新版本卡片新增**「用浏览器打开」**：应用内下载被网络掐断时，可以直接交给浏览器。
