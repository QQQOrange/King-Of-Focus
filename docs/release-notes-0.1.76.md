# v0.1.76 — 分心账本：被打断了几次，被谁

> 「今天被打断 7 次」没法照着改；「7 次里有 4 次是短视频」就能照着改。
> 这一版把拦截记成一张账，按天聚合、按次数排名。

## 一、账本怎么记

只管**真的被拦下**的东西：

- 应用被送回桌面（`monitor` 的拦截路径）
- 网页被关掉（插件上报的拦截路径）

"扫到了但放过"的窗口不记——那不算打断，记进去只会让账本虚高。

归并键：应用用**进程名**（`steam.exe`），网站用**域名**（`bilibili.com`）。
同一个目标多次命中合成一行，保留最近一次的命中规则名。

## 二、在哪看

「分心事件」页最下面新增一张卡：**今天被什么打断**

```
今天被什么打断                    共 7 次
  [软件] Steam — 某游戏          娱乐规则    3 次
  [网页] bilibili.com           网站也要管   2 次
  [软件] WeChat.exe             娱乐规则    1 次
```

一行一条：类型徽标（软件/网页）、显示名、命中的规则、次数。
次数最多的那一个，就是最值得关掉的那一个——这张卡存在的唯一目的。

## 三、实现要点

- `src-tauri/src/ledger.rs`：一天一个文件 `king of focus data/ledger/YYYY-MM-DD.json`，
  原子写；超过 200 条时丢掉"最久没出现"的那条，而不是拒记新的。
- `focus::note_block(shared, kind, key, label, rule)` 一个入口同时喂两处：
  HUD 的「打断 N」（内存计数，按段归零）与账本（按天聚合）。
- `ledger_today(limit)` 给页面用；`ledger_range(start, end)` 留给报告的"本期被打断 Top"。
- 日期不合法时返回空数组而不是报错——前端传奇怪参数不该把报告弄崩。
