# 0.1.97

继续清上一轮列出的"还没做"：这次全部是边缘路径和体验死角。

## 1. 「打开遮罩」这个按钮终于能用

总览里的「打开遮罩」在没选过目标窗口时只提示"先选一次"，然后跳到遮罩页——
而遮罩页**根本没有选窗口的入口**（`settings.mask.target_pid` 唯一的写入口是
`mask_start` 自己）。默认配置下这条 CTA 永远走不通。

现在它直接把窗口选择器弹出来（复用 `list_windows`），选中即开遮罩。

## 2. 睡眠锁屏不再每 1.5 秒重建

那层是全屏遮挡、唯一出口就是"积分解锁"按钮。以前每 1.5 秒 `innerHTML` 重建一次：
英文界面会退回中文，按钮节点被换掉、Tab 焦点掉回 body——键盘用户几乎没法解锁。
现在结构只建一次，之后只改文本与 `disabled`。

## 3. 键盘可用性

规则行、积分解锁行、窗口选择项都是 div（为了布局），Tab 到不了、回车没反应——
而积分解锁行是"被锁住时唯一的出路"。现在给了 `role="button" tabindex="0"`，
并加了统一的 Enter / 空格 → 点击。设置页的开关补了 `aria-label`（读屏不再只念
"复选框 未选中"）。

## 4. 统计与积分口径对齐

用积分解锁出来的自由时间，`monitor` 明确不给积分（"不算工作段"），但统计仍记成
"自律模式开启"。同一段时间两个口径。现在解锁窗口内统计也记到"未开启"。

## 5. 质押奖励不再重启白给

"干净跑完"奖励原来读进程内计数 `BLOCK_SEG/BLOCK_N`：重启归零、新段一次拦截就顶掉旧段。
押 10 分、被拦 5 次、重启，结算时按 0 次算，白给 +2。
现在 `Stake.blocks` 落到 `stakes.json`，`note_block` 时累加，结算读它。

## 6. 报告百分比终于加得到 100%

报告只存前 60 条明细，但占比的分母用的是全量时长——年报里"程序：3 小时（2.1%）"
加起来永远到不了 100%，也没有"共 N 项、列 M 项"的提示。
现在 `Report.onItems/offItems` 记下总条数，导出时用"列出来的这些项"当分母，并写明截断。

## 7. 边界与稳定性

- **区间校验按日期比较**：以前是字符串比较，`2026-9-1 ~ 2026-10-01` 会被判成"开始晚于结束"；
  `abc` 则一路通过、生成一份全 0 报告。现在先 `NaiveDate::parse_from_str`。
- **账本区间夹到 366 天**：`ledger_range("0001-01-01","9999-12-31")` 是 365 万次开文件，
  而且跑在 UI 命令线程上。
- **守护不再被并发拉起两份**：`existing_guard()` 只看 pid 文件，而子进程要过一会儿才写；
  两次检查间隔小于这个时间就会拉起两份。现在 5 秒内只拉一次。
- **系统时间回拨后睡眠倒计时失效**：倒计时按墙钟算，往回跳会让 `remain` 变成很大的正数，
  那一轮永远不到点。现在检测到时间倒退就按"刚唤醒"重新给满。
