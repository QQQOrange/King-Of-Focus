## 当日日历读取失败不再是"正在载入…"

统计页右侧那一天如果读盘失败，`dayFetch` 会清掉缓存并重绘——但 `dayHtml` 在
没有数据时只会显示"正在载入…"。于是失败一次就永远停在那句话上，
既没有错误提示也没有重试入口，用户只会以为界面坏了。

现在记下失败的那一天，显示"这一天读取失败 + 重试"；成功一次就自动清掉标记。
旁边那排（周/月网格）早就这么处理了，这一处漏了。
