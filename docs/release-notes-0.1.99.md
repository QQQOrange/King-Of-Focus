# 0.1.99

第五批：i18n 自检补盲之后暴露出来的 42 条英文漏翻，以及两处"看起来成功、其实部分失败"。

## 1. i18n 自检的第二个盲区

`check_i18n.js` 只扫 `>中文<`、属性、行首 `toast(`。像
`btn.textContent = '正在删除…'` 这种直接写进节点的文案**完全扫不到**——
英文界面残留中文，脚本照样报 100%。

现在补了三类模式：`.textContent/.title/.placeholder = '…'`、
`setHint()/say()/notify()` 这类自定义提示调用。语料从 752 条涨到 **801 条**，
立刻抓出 42 条漏翻（正在删除… / 检测中… / 请先粘贴令牌 / 删除这份备份文件？……），
全部补上，现在 801/801。

## 2. 插件 DNR 部分失败不再被当成成功

逐条重试时只要有一条写进去，`replaceDnr` 就返回 true，调用方于是记下指纹——
被 Chrome 拒掉的那几条（多为正则条数超限）在规则不变时**永远不会再尝试**，
用户只会莫名其妙地发现"某些网站拦不住"。

现在要求整批全部成功才算成功；只要有一条失败就不记指纹，下一轮重试。

## 3. 切换"自动遮罩"不再冲掉没保存的输入

分心事件页那个开关点一下会 `render()` 整页重建，把同一张卡上"重复提醒"里
刚敲进去还没保存的数字冲掉。现在只刷新数据、不重建页面（开关本身是原生
checkbox，视觉已经是对的）。
