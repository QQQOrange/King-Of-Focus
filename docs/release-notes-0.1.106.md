# 0.1.106 — 节奏：连续达标、周对比、年度热力图

这版不加"能做的事"，只加**能看懂自己**的东西。数据早就够了，缺的是判断。

## 一、节奏卡：连续达标 + 本周对比

统计页顶部多了一张卡，只回答三个问题：**连着多少天、这周比上周怎么样、今天达标没有。**

**达标怎么算**（`rhythm.rs`）：

- 当天自律时长达到当天计划（30 秒容差，跨零点不误判）；
- 且**写过的目标都做完**——目标第一次真正进入判定，而不只是待办;
- 没有计划的休息日**既不加也不断**，所以"周末没排班"不会把连续天数清零;
- 今天还没过完时，今天未达标**不算断**（从昨天往前数）。

周对比按**同期**比：周三拿本周一到三，对上周一到三。整周对半周只会得到"这周更差"的假结论。

## 二、年度热力图

统计页再往下一张：365 个格子，一格一天，越亮 = 那天自律模式开着的时间越长。

- 数据走新命令 `stats_heatmap`，**只回 date + 秒数**。复用 `stats_calendar` 也能画，但它每天带着软件明细，一年就是几百 KB;
- 读失败画"读取失败"，一年全 0 画"还没有可用数据"——**绝不**用空白冒充"你没努力";
- 一天只拉一次，同一天不再重复请求;
- 窄屏不折行，只横向滚动：热力图一旦折行，"哪一列是哪一周"就没了。

## 三、缓存与失效

节奏结果缓存 60 秒；写目标、打勾、改排班都会**立刻作废**（`rhythm::invalidate`），
不会出现"我刚写完目标，连续天数没变"这种让人怀疑数据坏了的瞬间。
