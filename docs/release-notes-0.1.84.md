# 0.1.84 / Android 0.5.2

## 一、手机端：首用向导

装完第一次打开，整屏就是三步。底部五个 tab、设置里十几项，用户不知道该先点哪个——
手机比电脑更需要这一步。

**① 你打算什么时候学？**
七个星期按钮（默认工作日）+ 起止小时（点一下往后走一小时，够用且不用引入下拉菜单），
下面实时算「工作日 20:00–22:00 · 每天 2 小时」。提示语是"先选一个你真能做到的时间——
小一点没关系"。

**② 这些时候，哪些不该打开？**
直接列出**已安装且有启动图标的应用**（最多 40 个，几百个滚到底反而没人选），点一下勾上。
自家应用不会出现在名单里。这一步可以全跳过。

**③ 就这样，可以开始了**
一张摘要：每周约几小时、挡住几个应用、完成后打开自律总开关。底下一句实话——
"真正拦住应用还需要「使用情况访问」或「无障碍」，完成后回首页，守护状态带会告诉你缺哪个"。

写进去的都是**既有结构**：`Config.days`（就是「时段」页那张表）+ 一条 `Rule`（就是
「规则」页里那条），不新造数据。设置 → 新手引导 → 重新走一遍，可以再放一次；
重走只覆盖向导自己写的那条规则（`onboard-rule`），不动你手建的。

老用户不会突然被弹：`onboarded` 是 `Boolean?`——老配置没有这个键 → `null` → 视为已走过；
只有 `Store.load` 发现**配置文件根本不存在**（真正的新装）时才显式写 `false`。

## 二、桌面端：复盘里给一条出路

周复盘第 4 题问「还剩 3 条，哪一条值得现在就处理？」，但以前没有任何入口能过去。
现在旁边多一个按钮：「去处理这 3 条」——直接跳到分心事件页。

只提问不给出路，那一问等于白问。
