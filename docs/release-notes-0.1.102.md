# 0.1.102 — 界面一致性统一

这一版不改功能，只把"同一个东西在不同页面长得不一样"的地方统一掉。
方法是**真的把每个页面渲染出来看**（无头浏览器逐页截图，深色 + 浅色各一遍），
不是读 CSS 猜。

## 1. 自律规则的卡片

| 问题 | 现象 | 修法 |
|---|---|---|
| 单条规则只占 1/3 宽，右边两大块空白 | `.sl-grid` 用 `auto-fill`，会保留空轨道 | 改成 `auto-fit`，一两条时撑满整行；下限 330 → 360px |
| 卡片信息折行，最后只剩一个「外」 | 330px 时「0 个软件 · 1 个网站 · 0 条例外」被挤断 | `.sl-item-meta` 单行 + 省略号 |
| 「删除」是中性灰，和别处的红色危险按钮不一致 | 规则页用的是 `btn btn-sm` | 换成 `btn-danger` |

## 2. 危险动作只有一种长相

以前两套样式混用：`.btn-danger`（12% 红底，9 处）和 `.danger-ghost`（透明底，10 处）。
同一屏里「删除」有的带底色有的不带，用户只会觉得"这几个按钮怎么不一样"。
现在两个类名合并成同一套规则（保留旧名字，老代码不用改），所有危险动作统一为
**红字 + 12% 红底 + 红边框**。

## 3. 圆角回到令牌

三处内联圆角是凭手感写的：`20px`、`8px`、`4px`，和 `--r-xl/--r-sm/--r-md` 对不上。
现在一律用令牌（关于页 logo、进度条、全局保护名单的文本域）。

## 4. 顺手清掉的魔法色

`var(--green, #52c41a)` 这种"令牌坏了就用一个和主题无关的绿"的回退去掉了——
回退值永远不会被用到，但读代码的人会以为主题里有两个绿。

## 怎么验的

`ui/_shot.html`（临时文件，已删除）在 `_harness.html` 的基础上加了一段：清掉启动弹窗、
按 `?view=` 渲染、按 `?theme=` 强制主题，然后用 Edge 无头逐页截图：

```powershell
msedge --headless=new --disable-gpu --window-size=1440,1000 --virtual-time-budget=7000 \
  --screenshot=out.png "file:///.../ui/_shot.html?view=rules&theme=light"
```

深浅两套主题各看一遍，重点核对了：卡片间距、标题层级、按钮尺寸、危险色、
空状态、分段控件。**发现的问题就是这个版本改掉的三类**，其余页面（总览 / 时段 /
统计 / 分屏 / 报告 / 云同步 / 设置 / 帮助 / 关于）在组件层面是一致的：同一套
`.card` / `.seg` / `.btn` / `.badge` / `.hint`，没有第二套按钮或标题样式。

顺带确认了两件事：

- 浅色主题的令牌是齐的（`--bg` / `--panel-*` / `--text-*` / `--line*` 全部有覆盖），
  实测 `body` 背景为 `rgb(245,246,250)`。
- 设置页的主题 / 语言 / 时长三组分段控件都走 `.seg`，不是三套。

## 还能再统一、但这版没动的

- **独立窗口**（HUD / 通知 / 睡眠锁屏）各自有一份令牌（`--hud-*` 等），
  数值目前和主窗口一致，但是**复制**的。要彻底一致得把令牌抽成
  `tokens.css` 供四个 HTML 共用——那是结构改动，风险大于收益，单独一版再做。
- 内联样式里还有 `gap:9px` / `margin-top:3px` 这类细碎值，视觉上看不出差别，
  逐条改只会制造噪音。
