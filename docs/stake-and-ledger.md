# 专注质押与分心账本

两份文件，两件事：**押了要有回报**（质押），**知道被谁打断**（账本）。
两端规则必须一致，改动前请两处一起改：

| | 桌面 | Android |
|---|---|---|
| 质押 | `src-tauri/src/focus.rs`（`Stake` / `settle_decision`） | `data/Stake.kt` + `core/StakeMath.kt` |
| 账本 | `src-tauri/src/ledger.rs` | `data/Ledger.kt` |

---

## 一、专注质押

### 为什么要做

积分以前只有**一个方向**：花掉买断锁机。那是纯惩罚性消耗——攒分只为了"逃跑"，
坐下专注本身没有任何账面回报。押一笔、跑完退回来（干净跑完还多一点），
才让"坐下来这一小时"变成有回报的事，而不是"忍到能花分"。

### 规则（唯一权威）

| 情况 | 结果 |
|---|---|
| 时段自然结束 | 退本金（10 分） |
| 自然结束且**这一段一次都没被打断** | 退 12 分（本金 + 20%） |
| 用积分提前退出（桌面：解锁；Android：暂停 / 停止） | **没收**，退 0 |
| 程序没开、跨过了结束时刻 | 下次启动第一拍补结算 |

"提前退出"定义得很窄，只有**花积分买断**这一条。关程序、关机、锁屏、被系统清理
都不算违约——否则会变成"忘了充电就扣分"，那不是在帮人自律，是在制造焦虑。

固定 10 分、不给输入框：押注要是能填金额，它就变成一道新的算术题，
而这道题最好的答案是"随便填个小的"。

### 结算时机

不挂在"时段结束通知"上。那条路依赖界面是否打开、通知是否发得出去，
机器休眠还会错过。结算放在后台每 20 秒一拍的循环里（桌面 `focus::tick_settle`、
Android `GuardService.maybeStake`），什么时候回来都能补上。

### 一条容易做错的细节（Android）

"被打断几次"必须按**这一节的时间窗口**统计（`LedgerStore.countBetween(seg, segEnd)`）。
只给起点的话，之后那几节的打断会把这一节的奖励吃掉，用户看到的是
"我明明一次没被打断，凭什么只退本金"。

## 二、分心账本

### 记什么

只记**真的被拦下**的东西：

- 桌面：应用被送回桌面（`monitor`）、网页被关掉（`server`）；
- Android：回桌面（`enforce` / `enforceMask`）、盖拦截页（`enforcePage`）。

"扫到了但放过"不记——那不算打断，记进去只会让次数虚高。
Android 的睡眠期拦截也不记：那是"该睡了"，不是走神。

### 归并键

- 应用：进程名（`steam.exe`）/ 包名（`com.bilibili.app`）；
- 网站（仅桌面）：域名（`bilibili.com`）。

同一目标多次命中合并成一行，保留最近一次的规则名。

### 30 秒去重（两端同值）

同一个目标 30 秒内重复命中**只算一次**（`DEDUP_SECS` / `DEDUP_SEC`）。
Android 的拦截判定是每秒轮询的，不去重会记成"被打断 300 次"；
桌面端调用点自己有节流，但口径必须一致，否则同样的行为在两端得到不同的数字。

### 存储

一天一个文件，超出 200 条时丢掉"最久没出现"的那条（不是拒记新的）：

- 桌面：`king of focus data/ledger/YYYY-MM-DD.json`
- Android：`files/kof/ledger/YYYY-MM-DD.json`

**不进跨设备备份**：这是事件流，两台设备各记各的才说得通
（在电脑前被打断的次数，不该算到手机头上）。

### 界面

- 桌面：「分心事件」页底部的「今天被什么打断」卡片。
- Android：同一页同一张卡（设置 → 分心事件）。

一张卡只做一件事：**次数最多的那个，就是最值得关掉的那个**。
没有数据时它不空着，会写"今天还没被拦过。要么很自律，要么规则没生效——去总览看看守护状态"。

**当前这一节**的次数另外还露在两个地方，用的是同一份账本，不另记一份：

- 桌面：HUD 顶部那行的「打断 3」（内存计数，段一变就归零）；
- Android：总览状态卡「这一节已被打断 N 次」、拦截页「这一节第 N 次被打断」
  （直接问 `LedgerStore.countBetween(段起点, 现在)`，所以和质押结算的"一次没被打断"是同一个数）。

拦截页那个数字是有意放上去的：被拦下的那一刻，"这是第 3 次"比任何一句"请专注"都管用。
