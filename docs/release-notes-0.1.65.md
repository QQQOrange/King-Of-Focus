# 0.1.65 / Android 0.4.2

## 修复：时段拖不上去了

旧实现只有"绝对时间平移"，撞到相邻块就停在边界上 —— 03:00–04:00 与 04:00–05:00
这种贴身排列，后者一个像素都动不了。现在拖动变成**重排**：

- 落点越过某块的起点 → 这一块插到那个位置，受影响的一段按原顺序、原长度重新排开；
- 往上拖齐平 → 排到它前面；往下拖齐平 → 落在手指所在的位置；
- 能拖到当天最顶部 / 最底部；
- 只影响旧下标到新下标这一段，区间外的块不动，总跨度不变，不会重叠。

## 拖动时的视觉反馈

- 被拖的块**浮起来**：外扩 1.5dp + 投影 + 2dp 对比色描边 + 更大的圆角；
- 块内直接写 `04:00–05:00`（块够高时），一眼看出动的是整段；
- 落点画**虚线占位框**，重排时跟着实时移动；
- 网格上方一行提示："正在移动 04:00–05:00 · 松手就放到这个位置"；
- 只有被拖的那一块高亮（以前整列都亮，像是选了整列）。
