# 0.1.64 / Android 0.4.1

## 强制模式：改成三道确认

点「强制模式」不再直接生效，依次确认三次：**意图 → 知情 → 最后确认**。
只有第三次选「是」才写配置；任何一次选「否」或按返回都回到原点，配置一个字不动
（"第几步"只存在对话框里，不存在于配置，所以没有中间态可残留）。

第 2 步会把生效期间的代价说清楚：不能暂停、不能跳过、不能用积分换时间、
只能用白名单应用、不能改设置、最长多久；当前能力不足时也会提示"强制模式会打折"。

## 修复：白名单模式下锁机失效

两个都在"兜底"上：

1. 拿不到遮罩能力（无悬浮窗 / Shizuku）时，`enforceMask` **直接 return** ——
   遮罩没盖上、也没回桌面，锁机等于什么都没做。现在降级为**回桌面 + 通知**。
2. `showLock` 的 800ms 节流是**丢弃**：`goHome()` 后 260ms 的那一发常被吞掉，
   表现为"回到桌面但没锁住"。现在改为**延后执行**。

顺带把"读不到前台"从"放行"改成"盖遮罩"（fail-closed）。

## 规则新增「白名单 + 黑名单同时生效」

`mode = both`：`packages` 是允许名单，`deny` 是禁止名单。
判定顺序固定：**禁止名单 > 允许名单 > 整机锁 > 名单外 > 放行**——
同一个应用两边都写了，按禁止处理。允许名单为空时退化成纯黑名单。

## 锁机页新增「白名单应用」入口

整宽描边按钮（2×2 圆点图标 + 计数徽标），点开是只读列表：
按显示名排序、点一下直接打开、没有可启动界面的如实标出。
白名单为空时按钮禁用（右侧写「暂无」）——不做"点了弹一个空列表"。
增删仍然只去「自律规则」，锁机页不提供任何管理入口。

## 「展示锁机页面」开关（规则页）

- 开（默认）：整机锁，按现有逻辑；
- 关：不锁整机，点开黑名单应用才弹 5 秒提示页并自动回桌面，其它应用正常用。
  这一档只看黑名单，白名单不参与判定（设置页里写明）。

提示页 5 秒**只在前台计时**：切后台暂停、回来继续；按返回 = 立即回桌面；
同一应用 3 秒内只弹一次；拉不起界面时降级为"回桌面 + 通知"。

## 自律时段内时段与规则都只读（含番茄休息）

以前只有专注阶段冻结，休息阶段可以改。现在**在时段内就冻结**：
允许趁休息改排班，等于允许把后半段全改了。三个付费出口（积分解锁 / 暂停 / 停止本段）仍然有效。
