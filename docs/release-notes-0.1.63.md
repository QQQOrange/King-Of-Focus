# 0.1.63 / Android 0.4.0

## 累计休息上限（两端一致）

「专注 25 + 休息 5」一小时跑两轮、休息合计 10 分钟。新增 `每小时休息上限`：
到上限后剩下的休息被截短、再往后整段跳过，**保持专注与锁机**。

- 端上位置：Android「时段 → 番茄节奏」；PC「自律时段 → 通用时长」
- 0 = 不限（默认，行为与上一版完全一致）
- 判定抽成一份纯函数：Android `ScheduleEngine.phase`、PC `clock::phase_at`，逐条对齐
- 随方案保存，也随 `.kofbak` 跨端带上

## 时段变成"块"，可以整块拖

- 同一段连续或重叠的窗口合并成一个圆角块，块内没有缝隙、跨小时不断开
- 长按块身 = 整块平移；按在块的第一格 / 最后一格 = 拉开始 / 结束时间
- 边界与冲突写死在一处：不越出当天、撞到相邻块停在它的边界上、至少留一个刻度、
  跨列拖动无效；平移时番茄节奏跟着走
- 相邻但**不同段**仍然不合并（锁机"停止本段"要靠段标识区分）

## 锁机提醒

- **开始前提醒**：提前 0–60 分钟可调，锁机与睡眠共用一个提前量，每一次只提醒一次
- **结束提醒**：不提醒 / 通知 / 弹窗 / 两者。弹窗需要悬浮窗或 Shizuku，
  拿不到时**降级成通知并写明**
- 暂停、停止本段、睡眠积分解锁**都不算结束**，不会误报
- 新增 `kof_lock` 通知渠道，可与阶段提醒分开关

## 震动与睡眠

- 进入锁机 / 睡眠时短震 180ms（可关）
- 睡眠期间**必须锁机**：不再提供"只统计不锁"的开关，老配置升级后按要锁处理
- 睡眠锁机不依赖自律总开关与锁机开关，也不受"暂停"影响

## 锁机期应用限制

新增「锁机期间的限制范围」：

| 模式 | 行为 |
|---|---|
| 整机锁（默认） | 除白名单应用与紧急通道，一律挡住 |
| 只按规则 | 有白名单 → 只允许名单内；只有黑名单 → 只禁黑名单 |

- 睡眠恒为整机锁，白名单应用仍可用（闹钟、笔记）
- 白名单优先于黑名单；输入法、来电、状态栏、权限弹窗永远放行
- 遮罩 / 拦截 / 睡眠共用同一个判定出口，不再各写一套

## 统计报告与 PC 对齐

报告改成 PC `report_out` 的同一套结构：标题 / 统计区间 / 时长总览（双轨 + 占比一位小数）/
开启与未开启的分布（分类 → 明细 top 8 → "另有 N 项"）/ 说明。周期跟随当前视图
（按日 = 日报、按周 = 周报、按月 = 月报）。

## 界面与性能

- 总览「今天」：今日自律总时长改为独占一行的大号主指标，次要指标一行小字，窄屏不再挤成两行
- 24 小时色条按覆盖率淡出，与网格里的"半格"一致
- 权限清单的应用数改为进程级缓存：那个页面每秒重组，之前每秒都在数一遍安装应用
