# v0.1.75 / Android 0.4.8 — 守护可见，目标上车

> 两个改动都指向同一件事：**别让"以为在自律"变成"其实没在自律"**。

## 一、守护状态带（Android 首页最顶部）

一条常驻状态带，三态：

| 情况 | 显示 |
|---|---|
| 权限齐备、服务在跑 | 绿色「守护中 · 权限齐备 · 拦截与统计都在跑」 |
| 缺权限 | 琥珀「现在没有在守护」+ 缺哪几项（如"无障碍服务、通知 缺失"），点一下直达系统设置 |
| 权限齐备但服务没跑 | 琥珀「守护服务没有在运行 · 点一下立刻把它拉起来」，点一下当场拉起 |

为什么单独一条、而不是并进下面的权限清单：Android 上服务被 Doze / 厂商清理后会**静默失效**，
用户以为还在被管着，其实早就不拦了。清单是"逐项体检"，可以慢慢看；这一条是"总开关状态"，
必须一眼可见。服务是否在跑用 `GuardService.isRunning()`（进程内标志，
`getRunningServices` 对第三方应用早就废了，不可靠）。

## 二、段目标（Android）

桌面 0.1.73 的「这一段要做什么」上手机：

- 专注锁机遮罩上方出现一行「＋ 写这一段的目标」，写完显示「目标：把登录页写完」。
- 点开写/清空；每 30 秒重算一次"现在属于哪一段"，跨段不会串。
- 时段结束的通知会带上目标（和分心条数一起），例如：
  `这一段结束了 · 目标：把登录页写完 · 记下 2 条想法，去「分心事件」逐条处理`。
- 分心事件页里，每个时段分组上方显示当时的目标。

目标存在 `kof/intents.json`，一段一条（再写即覆盖），上限 2000 条；不进跨设备备份。
