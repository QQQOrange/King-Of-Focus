# 0.1.68

## 弹层键盘与焦点：按清单修完 KOF-01 ~ KOF-07

清单见 `docs/keyboard-focus-checklist.md`（编号 / 优先级 / 文件:行 / 现象 / 修复要点 / 验收标准）。

### 修掉的两个「真问题」

**Tab 会把焦点送出弹窗。** 全局 keydown 只处理 Esc / Enter，没有 Tab 分支，也没
`preventDefault` —— 浏览器默认行为接管，焦点顺着主界面按钮一路跳，跳到外面再按 Esc
反而把弹窗关了。现在在 **capture 阶段**接管 Tab：取栈顶层里可聚焦的元素，自己算下一个
（支持 Shift+Tab 反向、首尾环绕），并且**无条件 preventDefault**。

**没有「当前层」的概念。** `#modalRoot` 一直是「谁想弹就 innerHTML 直写」，说不清该在
什么范围里循环。现在用观察器盯着它维护层栈（`.modal-mask` 即一层），**没有改那十几处
直写**——写法不变，行为统一。层名取自标题，Esc 只关最上面那层。

### 其他几条

- **输入法**：组合中按 Enter 不再提交（以前会存进拼音），长按 Enter 也只算一次。
- **Esc 穿透**：Esc 移到 capture 阶段并打标记，子组件 `stopPropagation` 也关得掉，且一次只关一层。
- **失焦兜底**：keyup / 窗口回焦 / 切回可见时，焦点跑到层外会被拽回来，次数可在自查面板看到。
- **事件通道**：层变化派发 `SubLayerChanged`（`{ count, name, at, escapes }`），
  首个消费者是时段页拖选（弹层出现时收尾悬停与手柄），后续接键盘引擎不用互相 import。
- **UIPI 说明**：快捷键卡片按权限显示「未提权时键盘钩子收不到管理员窗口的按键」，
  并指向已有的「以管理员身份重启」——这是系统限制，不是快捷键没注册。
- **自查入口**：设置 → 快捷键 → 「键盘与焦点自查」，面板自己就是一个层，实时显示
  层数 / 层名、可聚焦数与焦点位置、拽回次数、权限；按 Tab 就能亲眼看到焦点是否只在面板内循环。

### 顺带修掉的隐藏缺陷

| 现象 | 根因 | 修复 |
|---|---|---|
| 带实时读数的弹窗按 Esc / 点 × 没反应 | `closeModal` 的退场保护把「任何 childList 变化」都当成新弹窗，而内部 `textContent` 刷新也算 | 只认「新插入 `.modal-mask`」 |
| 两层叠着时一次 Esc 关掉两层 | `closeModal` 取第一个 `.modal-mask` 并清空整个 `#modalRoot` | 多层时只摘栈顶，单层仍走原动画 |
