## 两个脚本 bug（都修了，都值得记）

1. **死循环**：`while old in s: s = s.replace(old, new, 1)` —— 替换结果里**还包含**原中文
   （`Loc.p("Upload", "上传")` 里就有 `"上传"`），于是永远匹配得上。跑到 420 秒被我掐掉。
   改成单趟 `str.replace(old, new)`（Python 的 replace 不会回头再扫新插入的文本）。
2. **Python 引号**：英文里带 `"unknown error"` 这种内嵌引号，用 `"..."` 包就语法错误。
   改成 `r"""..."""`——**raw 是关键**，否则 Kotlin 的 `\n` 会被 Python 解释成真换行。
