# 0.1.118 / Android 0.7.2 — 英文界面第二屏：设置页

上一版立了 `Loc` 机制、覆盖了导航与总览。这一版把**设置页**整屏英文化——它是文案最多
的一屏（225 条唯一中文字面量，占全部 1657 条的 14%）。

## 做了什么

- `SettingsScreen.kt` 里 **198 处**中文字面量包成 `Loc.t(…)`；
- 新增 **175 条**英文译文，覆盖：通知与四个提醒渠道、拦截与锁机（含强制/温和、暂停价格、
  限制范围）、睡眠、云同步（WebDAV、上传/下载/合并/覆盖、自动备份）、分心事件、每周复盘、
  新手引导、数据与保留天数、分区恢复、关于、保活体检、以及全部确认弹窗；
- 带插值的句子（如「汇总时间 21 点」「保留 400 天」）改为 `Loc.isEn` 分支 + `Loc.t(" 点")`
  这样的**单位片段**，既保住了 Kotlin 模板，也不用拼格式串。

## 覆盖率

| 屏 | 状态 |
|---|---|
| 底部导航 + 总览 | ✅ 0.7.1 |
| **设置** | ✅ **本版** |
| 统计 / 时段 / 锁机 / 规则 / 分心 / 守护通知 | 仍是中文（约 76%） |

按当前进度，剩下四屏各一版即可收口。

## 闸门仍然在

`LocCoverageTest` 两条断言照常生效：

- **235 条** `Loc.t` 全部有译文（漏一条就红）；
- 词典没有堆积死条目。

写这一屏时它真的救了场：包了 198 处之后，测试立刻报"缺 175 条译文"，
一条不多一条不少——这正是我想要的反馈方式，而不是让英文用户去发现。
