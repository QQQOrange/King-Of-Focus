# 0.1.91

接着 0.1.90：**手动开遮罩时，HUD 上那个时间该干什么。**

0.1.90 让 HUD 在没有自律时段时也显示（它是「记一笔」的入口），但计时器还是原来那套——
自律时段里显示"这一轮专注了多久 / 距离结束还有多久"，没有时段时就是 `00:00:00` +
「本时段没有设定结束时间」。一块永远不动的表，看着像坏了。

## 现在它是一块手动专注秒表

手动开遮罩时（不在自律时段里）：

- **大数字 = 这次遮罩已经开了多久**，从打开那一刻开始走，关掉就归零。
- **第二行**按优先级说三件事：
  1. 连续坐满 **90 分钟** → 「已连续 1 小时 30 分 · 起来走两步？」（只在这一模式下出现，
     自律时段里的番茄节奏本来就管这件事，不重复唠叨）；
  2. 否则显示 **「今天已专注 2 小时 10 分」**；
  3. 今天还没开始（0 秒）→ 「想到什么就点左上角记一笔」，把唯一的按钮指出来。
- **标签**是「遮罩中」，不是「专注中」——后者会让人以为在按自律时段计时。

## 配套：手动遮罩的时长现在算"专注"

统计原来只把「规则生效 / 时段专注 / 固化」记进 `on`，其余记 `off`。手动开遮罩的时间
一直落在 `off`（休息）里——统计页上看着像在摸鱼，而 HUD 又要用它显示"今天已专注多久"，
两边必须是同一个数。现在 `stats::sample` 把手动遮罩也算进 `on`。

这一改同时影响周/月报里的"专注时长"：我认为这是对的——用户主动把屏幕盖上去做一件事，
那就是专注，不该记成休息。
