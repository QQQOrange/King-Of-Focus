# 0.1.107 / 插件 1.2.0 — 页面侧的两件事、战报图、安全模式

这一批是"上次清单里的另外三个"。手机遥控按你的要求没做。

## 一、插件 1.2.0：藏推荐流 + 网页里的专注条

插件第一次有了**页面侧脚本**（`content.js`）。它只读状态、只做两件事：

**1. 藏起首页推荐流**（设置 → 拦截行为，默认关）

YouTube / B 站 / 知乎 / 微博 / X 的**首页信息流**会被隐藏，其余照常：

- 只认"首页"路径（YouTube 的 `/`、B 站 `/`、知乎 `/` 与 `/follow`、微博 `/`、X `/home`）；
- 搜索、播放页、私信、通知**一律不碰**——改坏一个网站比少拦一会儿更让人恼火；
- 藏完原地留一句说明（"推荐流已按 King Of Focus 的设置隐藏"），否则用户只看到页面空了，以为网站坏了；
- 单页应用切路由不会重新注入脚本，所以挂了 MutationObserver，必要时重挂；
- 选择器失配时**什么都不做**，不会把页面搞乱。

**2. 网页角落的专注条**（默认开）

自律生效时，每个网页左下角挂一条「自律中 · 剩余 42:10 · 规则名」：

- 放左下角而不是顶部横条：顶部会盖住站点自己的导航（YouTube/B 站都在 top:0）；
- 点一下收成一个小圆点，不挡内容；
- 浏览器全屏时主界面看不见，这条是唯一还看得见的提醒；
- 状态从 `chrome.storage.local` 读（background 每轮 refresh 写入），**网页脚本不直接访问 127.0.0.1**。

## 二、战报图 + 洞察

**战报图**：统计页「战报图」按钮 → 1080×1350 竖版 PNG（canvas 画，不引第三方库）。

里面是：区间总时长、连续达标、今日目标、本周时长、花时间最多的三个应用（带条形）、
一句结论、生成日期。存图走系统保存对话框（`poster_save`：解析 data URL → 写文件，
base64 解码自己实现，30 行 + 4 条单测，不新增依赖）。

**洞察**：节奏卡下面多一句人话结论，例如
「你最常在 09:00–11:00 进入状态；本周比上周多出 18%；已经连着 6 天达标。」
（按 2 小时合并桶找峰值——单小时峰值受一次会议影响太大。）

## 三、安全模式

`panic = "abort"`，所以"启动就崩"是**每次启动都崩**，用户连设置页都进不去，只能删配置。

现在：

- 两次启动间隔 < 120 秒算一次异常启动，连续 3 次 → 安全模式；
- 安全模式里 `discipline::active_rules` 直接返回空：**不拦软件、不下发网页规则、不画遮罩、不自动打开**，统计照常记；
- 每一页顶部挂红色提示条 + 「退出安全模式」按钮；
- 这次启动活过 90 秒 → 自动清零计数、退出安全模式（后台线程，不依赖异步运行时）；
- 判定只在 `active_rules` 一个入口做——分散到各处迟早漏一处，那就是"进了安全模式还在被关程序"。

## 六、还是没做的

- **新标签页替换**：`chrome_url_overrides` 接管新标签页是个强体验决定（会把用户的新标签页换成我们的页面），
  不该顺手做；
- **全屏独占游戏**：需要检测独占全屏并切桌面，风险高，得单独验证；
- **令牌统一（tokens.css）** 与 **get_state 增量**：纯内部重构，零用户可见收益，
  但会碰到 4 个独立窗口与每 1.5 秒的状态协议——放在专门一轮做更稳。
