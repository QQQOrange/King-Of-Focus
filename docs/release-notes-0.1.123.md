## 这一批的关键：嵌套引号

`Loc.p` 的两份成品都是 Kotlin 字符串字面量，而 `${ }` 里 Kotlin **按代码解析**：
`"…${x.ifBlank { "—" }}"` 这种写法在原句里合法（插值里是独立表达式），
但一旦被我的脚本按外层字符串转义成 `\"—\"`，就变成非法代码——上一版
`ReviewScreen.kt` 就是这么被弄坏的。

这次改成**先算变量再拼**：

```kotlin
data = run {
    val dash = "—"                     // 在块里是普通字符串，不涉及外层转义
    Loc.p("…${x.ifBlank { dash }}…", "…${x.ifBlank { dash }}…")
}
```

脚本也换了策略：不再用正则在全文里猜，而是**逐条给出原文整行与新行**，
`assert count == 1` 保证只命中一次、命中不了就报出来而不是硬改。
